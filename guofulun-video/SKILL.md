# 「看得见的手」·《国富论》视频制作（项目技能）

完整手册在本技能目录的 `handbook\`（2026-10-29 版；在用户电脑上另有一份 `D:\AI\短视频\00_交接包_国富论短视频制作手册\`，内容相同）。这里是入口和最要紧的规矩；细节一律以手册和项目“真身”为准：`D:\AI\短视频\CLAUDE.md`（从最上面的 ★★★★ 读起）、`D:\AI\短视频\模板\*.md`、`D:\AI\短视频\00_国富论系列规划.md`。

## 开工先读
1. `handbook\00_先读我.md` → `规范\30_规则优先级与版本演进.md` → `规范\31_用户偏好与沟通方式.md`
2. `流程\10_总流程一览.md`，再按要做的那一步读 `流程\11–24`
3. 规划表找下一集；上一集的 `studio\episodes\epXX\审核记录.md`（改稿记录里有用户亲自定的东西）
4. 样板：`样板\场景代码_ep23\`、`样板\剧本样板_ep23_script.json`

## 一集的流程（命令在 `D:\AI\短视频\studio`）
1. 知识卡 `episodes\epXX\知识卡.md`：按原文顺序列全，英文短引（Wikisource / 古登堡 #3300）
2. 定唯一的问题，翻成“观众心里那句话”
3. **【先问用户】** 3–4 个开头候选（写到三问卡）+ 需要的角色（仓库没有的先说）
4. 设计：同一问题三步、第三步边界、一个案例、真异议、点名概念、别套错；开拍前五问
5. 剧本 `episodes\epXX\script.json` → **【先问用户】过目** → G 节逐句 + `check_prose.py` → 第 1 关审核
6. `python gen_assets.py epXX`（后台）→ 画面 `src\epXX\`（照 EP23，`Root.tsx` 登记）→ `npx tsc --noEmit -p .` → `handbook\工具\anchors_check.py`、`kwdup.py` → `python review.py epXX`
7. `python produce.py epXX --skip-audio`（后台）→ `工具\frames.py` 抽帧两轮、`hook_timeline.py`、`loudness.py` → 封面三张 → 第 2 关审核
8. `EPXX_发布文案.md`（`工具\check_titles.py`）→ 更新规划表 → 交付（如实说没做 / 没验证的）

## 最要紧的规矩（10-29）
- 全部中文回复；选项写在正文里
- 开头：大字 ≤12 字、第一句 ≤2.5 秒说观众心里那句话；2.5–6 秒本集角色说损失；第 3 句“《国富论》里说……”；三问一句 ≤6 秒；18 秒前进故事；前 30 秒有顶嘴
- 一集一个问题；不让观众回答；“斯密”≤2；不评价今天的政策；不制造恐慌、不编真人
- 画面：`look="paper"` 书页外框 + `PaperTown` + v16 彩铅角色（只用仓库里的）+ 页眉下 `PartBar`；每个镜头只放相关角色、主道具外还有在动的东西
- 片长 3:45–4:30（EP22、EP23 在试 3 分钟）；公式卡念完停 2–3 秒
- 文件名带集号；发布标题 ≤20 字、置顶评论先讲经济学、晚上 20–22 点
- **用户亲自定的开头、封面问题、标题、角色不擅自改**；用户的决定当场写进审核记录
- 不读不转发 `studio\.env` 密钥；不登录抖音；下载前先问；不改别的对话和心理号的文件；已发布的集不重做
- 用户指出的错误写进 `模板\审核清单.md` F 节并告诉用户
