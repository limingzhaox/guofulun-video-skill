# 工具说明（质检小脚本，2026-10-29 用 EP23 实测通过）

> 依赖：`pip install imageio-ffmpeg pillow`。用完整路径运行，例：`python "D:\AI\短视频\00_交接包_国富论短视频制作手册\工具\est_length.py" ep24`。
> 这些脚本**只读不改**项目文件。

| 脚本 | 什么时候用 | 做什么 | 用法 |
|---|---|---|---|
| `est_length.py` | 剧本写完、配音前 | 用已配音的一集当基准估片长；数“书里”“斯密”“《国富论》” | `python est_length.py epXX [基准集，默认 ep23]` |
| `anchors_check.py` | 写完画面代码 | 每个 `W(i, "词")` 的词在第 i 句里有没有、是否唯一 | `python anchors_check.py epXX` |
| `kwdup.py` | 写完画面代码 | 顶部关键词 `Keyword` 有没有和同场景字幕一字不差 | `python kwdup.py epXX` |
| `hook_timeline.py` | 配音后 / 出片后 | 第一句几秒、角色几秒开口、书名第几句、三问多长、几秒进故事、前 30 秒角色台词 | `python hook_timeline.py epXX` |
| `frames.py` | 出片后 | 成片按句抽帧，拼联系表（每页 21 句）+ 句号对照 | `python frames.py <EPXX_成片.mp4> <studio\src\epXX\timeline.json> <输出目录> [比例 0.8]` |
| `loudness.py` | 出片后 | 整体响度、真峰值、LRA，判合格 | `python loudness.py <EPXX_成片.mp4>` |
| `check_titles.py` | 写完发布文案 | 标题 ≤20 字无前缀、3–4 个；概念小节字数；标签 15–20 个；置顶评论没有互动、以“这一集的经济学”开头 | `python check_titles.py <EPXX_发布文案.md>` |

另外：
- 文案模型腔检查：`python "%USERPROFILE%\.claude\skills\human-writing\scripts\check_prose.py" <文本文件>`
- 出片前总览：`python review.py epXX`（studio 自带）

**EP23 实测结果**：估 165 秒 / 实测 172 秒；63 个锚点 0 错；26 个关键词 0 复读；第一句 2.3 秒、角色 2.7 秒、三问 4.4 秒、17.4 秒进故事；发布文案标题 4 个都合格，概念小节 207 字（超了模板的 80–150，提示压一压）。

抽帧建议：先抽 0.8（每句快说完，元素都该出来了），再抽 0.92 或 0.55；输出放临时文件夹或 `抖音账号\视频矫正\_work\EPnn_主题\`，结论写回审核记录。
