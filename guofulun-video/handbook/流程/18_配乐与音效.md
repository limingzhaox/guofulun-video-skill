# 18 · 配乐与音效

> 配乐和音效都由脚本程序合成（没有版权问题）。**发布时不要再加抖音曲库音乐。**

## 一、配乐
- 剧本顶层 `"music": "baroque"`：D 大调羽管键琴卡农式进行；亮场 16 分音符、dusk 冷调场稀疏 8 分音符、暗场换低沉铺底（`bgm_dark.wav`）
- 场景 `"hush": true`：这一场开始前约 1 秒配乐降到无声（暗场反转用）
- `"bgm_db": -4`（可选，EP51 起）：整集配乐压低几 dB（轻后期的人声起伏大，配乐让一点）
- 其他取值 `piano`、`piano_emotive`、`chip` 是心理号用的，国富论号不用

## 二、混音（用户三次试听后定，**没有用户反馈不要改**）
`studio\src\Episode.tsx`：`V3 = { base: 0.34, duck: 0.3, dusk: 0.25 }` + `<Episode mix="v3">`
- 配乐在人声下约 16–17 dB；句间空隙约低 14 dB；说话时只轻压约 3 dB；冷调段再降 25%
- 每个场景开头提前 6 帧响一声翻页；`cold`：配乐第 0 帧满音量进场

## 三、音效（`studio\public\sfx\`）
| 名字 | 用在 |
|---|---|
| `ding` | 第 0 帧物件弹出（第 2–3 帧）、提示 |
| `pop` | 卡片、标签、物件出现 |
| `boom` | 结论章、核心句（砸重点） |
| `stamp` | 红章落下 |
| `tick` / `paper` | 翻转、换段、翻页 |
| `buzz` | 否定、错误 |
| `swish` | 转身、东西飞过去 |
| `boing` | 角色跳一下、出场 |
| `thump` | 放下重物（粮袋） |
| `coin` | 金币、钱 |
| `pour` | 倒粮 |
| `clack` | 织布梭子 |
| `tap` | 脚步 |
| `twinkle` | 亮晶晶 |
| `hammer`、`whoosh`、`steam`、`type`、`blip`、`doorbell`、`erase`、`msg`、`ring` | 按需 |

（`boing coin pour clack tap twinkle swish` 是 `make_sfx16.py` 新合成的，只新增不覆盖）

用法：`<Sfx at={帧} name="pop" v={0.26} />`。**每个动作一个、每个重音字最多一个**，克制；常用音量：pop 0.24–0.3、ding 0.3–0.35、boom 0.4–0.45、stamp 0.36、swish / boing 0.18–0.2。

## 四、响度（成片）
`produce.py` 自动：两遍线性标准化到 -14 LUFS + 4 倍采样率限幅（真峰值 ≤ -1 dBFS）。
交付前用 `工具\loudness.py` 复测：-14 LUFS（±0.5）、真峰值 ≤ -1 dBFS、短期波动（LRA / P90−P10）≤ 3 dB。
只改混音不改画面：`python produce.py epXX --remaster`。
