# 23 · 发布文案与发布

> 文件：`D:\AI\短视频\EPXX_…\EPXX_发布文案.md`（出片时从模板复制，之后不覆盖，手写）
> 模板：`模板\发布文案模板.md`；样板：`样板\发布文案样板_EP23.md`（最新）
> **AI 只写文案，发布由用户自己做**（AI 不登录抖音）。

## 一、格式（10-24 定）
- 每一块能复制的内容放**单独的代码框**：每个标题、作品描述、经济学概念、20 个标签、5 个标签、置顶评论
- 标题**不加**“Vibe知识大赏｜”前缀；**每个 ≤20 字**（含标点）、主谓齐全
- 不要求观众回答（标题、描述、置顶评论都不写“评论区打 1/2”）
- 文件开头用引用块写本集的特别说明（新规矩第几集、试验什么、只讲什么年代、不对今天的什么下判断）

## 二、标题（3–4 个，选一个发）
| 类型 | 例（EP23） |
|---|---|
| 1. 和开头、封面一致（推荐） | 城里人和乡下人，到底谁养活谁？ |
| 2. 吊一个反常识的事实 | 城里一粒粮也不长，凭什么越长越大？ |
| 3. 人人能猜的二选一（至少 1 个） | 种粮的和做衣服的，谁更离不开谁？ |
| 4. 口头禅 + 为什么 / 具体的数 | 为什么先有乡下，后有城市？ |
写完用 `工具\check_titles.py` 数字数。

## 三、作品描述
```
国富论23｜（和片子第一句一致的问题）
（角色那两句 + “《国富论》里说……”）
第X篇第Y章：（三问原句）
下次再……，先问一句：……？
本视频仅为读书分享，……讲的是书里那个年代，不对今天的……下判断，不构成投资建议。
```

## 四、这一集讲的经济学概念（10-28 起每集都写，80–150 字）
```
概念：书里叫“……”｜今天常说“……”（现代解释）
核心：（两三句：机制怎么运作 + 本集问题的答案）
别套错：（一句适用条件）
```
书里的说法和今天的术语分开写；今天的术语只当借来理解的工具，不说成斯密原话。

## 五、话题标签
- 20 个一次给全（书名作者 + 本集主题 5 个 + 人群痛点 / 相关领域 4–5 个 + 内容类型）+ 一个“只能放 5 个时”的精选
- **活动期（到 2026-10-31）带 #vibe知识大赏；之后换成 #涨知识**
- 用 `工具\check_titles.py` 数个数

## 六、置顶评论（10-29 改：先讲本集的经济学）
```
这一集的经济学：（概念、机制、本集问题的答案，3–5 句；这里可以说“斯密说”）
出处：《国富论》第X篇第Y章。“……”是今天的说法，不是斯密原话；“……”是举例；……是动画人物。
下一集：（下一集的问题）
```
**不加互动提问**（10-28、10-29 用户两次确认；外部意见建议的“你最近少花钱，是……还是……？”不要）。

## 七、发布设置（文案末尾写给用户）
- 上传 `EPXX_封面_3比4.png`（横屏 `EPXX_封面_横屏.png`），视频 `EPXX_成片.mp4`
- 合集：一口气读懂《国富论》；作品声明勾“内容由 AI 生成”；领域选知识 / 人文社科
- **发布时间：晚上 20:00–22:00**（10-29 起，粉丝活跃高峰）；写明排在哪一集之后发
- 有试验的写清看什么（新开头：看 2 秒跳出、5 秒完播；EP22 是 3 分钟片，和 4 分钟的几集比平均播放）
- 话题：#vibe知识大赏 活动截止 2026-10-31，之后换成 #涨知识（`模板\发布文案模板.md`）
- 成片自带配乐，**不要**再加曲库音乐；发布后 1 小时内回复前 10 条评论
