## 一、竖屏“问题在上”版式长什么样（10-28 定、10-29 调）
- **问题**上移到集数下面：112 号两行
- **书**缩小放左下当系列标识（`bookS` 0.64），腰封只印一行小字
- **右下**画本集的矛盾场景（`motif`，原点约 (700, 1310)）+ **一个有表情的本集角色**（开头那个，身高约 240px，配一个 `Emote` 冒汗 / 问号 / 感叹号），占比要小
- 照旧：左上账号名片（头像 + “看得见的手” + “把经济学，画给你看”）、右上中文“**第 XX 集**”（汇总集“第一篇 总结”，不用 EPISODE / BOOK）、章节名、底部合集条
- **彩蛋**：只藏一只长毛猫、一只金币狗（竖屏身高约 70–85px、横屏 65–75px），藏在书顶、书脚这类角落；别的角色不上封面（右下那个本集角色除外）
- 用户说过“不要完全按外部意见改”：不去掉书、不改问题文字、不加别的元素

## 二、Cover.tsx 写法（EP23）
```tsx
const P = {
  ep: 23,
  title: [<>城里人和<span style={{ color: "#E8604C" }}>乡下人</span>，</>, <>到底<span style={{ color: GREEN }}>谁养活谁</span>？</>],
  chapter: "第三篇 第1章 · 财富的自然进步",
  obi: "城里一粒粮也不长",
  motif: (<g><CrayonDefs /> …本集矛盾场景（田 + 粮袋 + 镇子）… </g>),
  peek: { front: (<>
    <Sprite id="cat" view="front" x={250} y={854} h={72} seed={9} shadow={false} />
    <Sprite id="dog" view="front" x={130} y={1330} h={84} seed={13} shadow={false} />
    <Sprite id="folk_farmer" view="front" x={690} y={1340} h={240} seed={61} shadow={false} />  {/* 开头那个角色 */}
    <Emote x={760} y={1090} kind="!" at={-20} dur={100000} s={0.8} />
  </>) },
  peekWide: { front: (<> …横屏只放猫狗彩蛋… </>) },
};
export const Cover: React.FC = () => <BookPoster {...P} layout="question" bookS={0.64} />;
export const CoverWide: React.FC = () => <BookPosterWide {...P} />;
```
`index.ts` 导出 `{ id, Video, Cover, CoverWide, tl }`。

## 三、文字规矩
| 项目 | 规矩 | 例 |
|---|---|---|
| 两行问题 | = 片子开头那个问题；**两行合起来主谓齐全**、说清是哪样东西；每行 ≤8 字（9 字加逗号会折行） | ✅“城里人和乡下人，/ 到底谁养活谁？” ❌“为啥有的越买越贵”（主语含糊） |
| 用户定的问题 | 不擅自改（EP21 封面用户定“银行存款利息越来越低，/ 是因为钱变多了吗？”） | |
| 腰封 | 不给答案，吊一个数或悬念；和口播一致（EP22 “最多”改“有时能”时三张封面腰封一起改） | “城里一粒粮也不长” |
| 章节名 | “第X篇 第Y章 · 章名” | |
| 汇总 / 番外 | `ep` 传文字（“第一篇汇总”），右上印“第一篇 总结” | |
