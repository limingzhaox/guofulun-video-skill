# 17 · 配音

> 命令：`python gen_assets.py epXX`（在 `D:\AI\短视频\studio` 下，后台跑）
> 引擎：火山引擎 · 豆包语音合成 2.0；免费备用 edge-tts（`--engine edge`，只作临时预览）
> 密钥：`studio\.env`（**永远不要读出来、贴进对话、写进文档**）

---

## 一、它做了什么
1. 逐句调火山引擎合成（带逐字时间戳）→ `public\epXX\audio\<场景>_<句号>_<哈希>.wav`
2. 逐句统一响度（`level_voice`）；剧本顶层 `"level": "gentle"` 时改成轻后期（终章用）
3. 排时间：开头 0.25 秒、句间 0.10 秒、场景间 0.32 秒、每个 `⏸` 多 0.45 秒、场景 `pause` 再加、结尾 1.6 秒
4. 写时间轴 `src\epXX\timeline.json`；生成配乐；打印总时长和每个场景的起点、时长
5. 缓存：哈希 = 引擎 | 音色 | 语速 | 语气说明 | 文字（设了 `max_pause` 再加一项）。只有改过的句子会重新配音；只加减 ⏸ 不会

## 三、开头和特殊场景的语气（10-26 用户）
- **开头场景**单独写 `context`：“像跟朋友聊天时，说出一个大家常拌嘴的问题，带一点笑意和好奇，自然、从容、不着急”，并设 **`"rate": 14`**（10-26 晚用户：“语气有点太着急了，稍微带一点语气就好”；“上扬、挑衅”的写法作废）
- 三问那场：“三个问题一口气问完，轻快、不着急”
- 暗场 / 有分量的场景：`"context": "语气沉稳、放慢，带一点分量"`

## 四、用户自制音色（终章 EP51 起；10-28、10-29 三轮试出来的定稿“E 版”）
- 音色 ID `S_你的复刻音色ID`（用户在火山引擎声音复刻里录的）。**必须走资源 `seed-icl-2.0`**：剧本 `tts` 里写 `"resource_id": "seed-icl-2.0"`（`seed-tts-2.0` 会报 “resource ID is mismatched”）
- **情绪开关对复刻音色都没用**：`context` 写语气说明反而更平；正文前写“[开心地]”会被念出来；emotion 参数基本无效；speech_rate 作用弱
- E 版设置：语速基调 16、**不写任何语气说明**；讲故事的场景 `"rate": 20`、安静的场景 14；真心话和关键句行首加 `〔slow〕`（剧本顶层 `"slow_rate": 6, "slow_pre": 0.35, "slow_gap": 0.7`）；关键句重新断句，多用逗号、感叹号、省略号；顶层 `"level": "gentle"`、`"max_pause": 0.4`；配乐让一点：`"bgm_db": -4`
- 想更有感情：只能请用户自己录那几段，或重录复刻样本

## 五、看片长
- 跑完看 `配音引擎 volc，总时长 XXX.Xs，N 句`
- 3 分钟试验集 170–195 秒；标准集 225–270 秒；超了删句子，不提语速
- 公式卡那句念完只停 2–3 秒（cta 句末 1 个 ⏸）

## 六、出错时
| 报错 | 处理 |
|---|---|
| HTTP 401 / 403 | 密钥、余额问题，让用户去控制台看，不要让用户把密钥发给你 |
| 音色不可用 | 控制台开通，约 1 分钟生效 |
| resource ID is mismatched | 复刻音色要 `"resource_id": "seed-icl-2.0"` |
| 超时 | 自动重试 3 次；再失败隔一会重跑（已配好的有缓存） |
