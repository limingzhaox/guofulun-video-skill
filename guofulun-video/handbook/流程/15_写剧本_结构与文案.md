## 二、每类句子怎么写

**开头**：用户选定的原句，一字不改（只改通顺和事实错误，并说明）。
```
城里人和乡下人，谁养活谁？
农夫：全城吃的粮，都是我种的。
阿禾：你身上这件衣服，可是我做的。
《国富论》里说，城里吃的用的全靠乡下，可城里挣的，不是从乡下抢来的。⏸
城里拿什么换乡下的粮？为什么先有乡下才有城？地便宜的地方，城还长得大吗？
```

**每一步**：
```
案例句：镇子刚有的时候，农夫想要一件衣服，只能自己缝，一缝就是十天。（创作示例，facts 标明）
变化句：现在他拿三天种出来的粮，去跟阿禾换，衣服当天就穿上了。
异议句：小满：那粮都让城里人吃了，农夫不亏吗？            ← 单独一行，真不服气
论证句：不亏。书里说，乡下人拿少得多的劳动，换回多得多的东西；……   ← 解释换方向
细节句：离镇子越近越划算。一英里外种的粮，和二十英里外运来的卖一个价，……
角色句：农夫：这么一算，我还赚了。
结论句：城里一粒粮也不长，……两边都赚了。⏸                  ← 口播一句普通话结论；画面盖“第一步的结论”章
```

**结尾**：
```
回到开头那个镇子。
城里人和乡下人，到底谁养活谁？书里说，他们互相是对方的仆人。⏸
书里把这个顺序叫“财富的自然进步”，……
今天常说，农业先得有剩余，城市才长得起来。                 ← 标明“今天常说”
不过别套错，书里说的是靠人力种地、靠马车运粮的年代。……       ← 适用条件
下次再听到谁养活谁，先问一句，他们拿什么跟对方换？⏸
```
**预告（cta）**：用下一集要回答的问题勾住：“可近代欧洲偏偏把这个顺序倒了过来，几百年里，地主都不好好种地，为什么？下一集接着讲。⏸”（下一集的开头要接得住这个预告）

## 三、写法规矩

| 规矩 | 来历 |
|---|---|
| **全片不让观众回答**；问题只用来钩住人，停顿后自己揭晓 | 10-23 |
| 第一句“你有没有想过，＋本集问题”（约 4 秒）、一句只用一种语气；第 3 句报《国富论》 | 10-30、10-31 |
| 每一步至少 2 个演示动画，写在知识卡第五节，剧本里在对应句子旁注明 | 10-30 |
| “斯密”≤2 次（EP23 是 0 次）；“书里说”可以多用 | v5 |
| 一句只说一件事；一段话（标点隔开）尽量 ≤20 字；>30 字拆短 | 10-24 |
| 同一个东西全片同一个叫法；当代说法和书里说法分开 | EP12“租子” |
| 比喻、形容核常识（金银很重） | EP13 |
| 结论用两种情况对照，不用要换算的比较句 | EP14 |
| 不比原著说得绝对：most men → 大多数人；upon equal, or nearly equal profits → 利润差不多的时候；“多半”不说成“只有” | 审核 B 节 |
| 假设说清是假设：“要是在北美那些殖民地……”“假如……” | 10-27、EP23 |
| 不用“增值 / 贬值”这类投资词；不评价今天的政策（降息、贸易、城乡户籍） | EP15、EP21、EP22 |
| “回到开头”最多两次（第一部分结尾、结尾） | 10-28 EP19 |
| 观点 / 认知只在一两个重点用“所以……”从画面点出来，不说“我认为”“我觉得” | 10-25 |
| 不用“先猜一猜”“打 1 或 2”这种无所谓的提问 | 10-25 |
| 现实处境可以带，但不下“经济下行”断言、不制造恐慌 | 10-28、10-29 |
| 角色台词单独一行，行首“名字：”，名字在 `tts.cast` 里 | EP12 |

## 四、facts 怎么写（三类分开标）
```
"城里吃的用的全靠乡下：Book III Chapter I——The country supplies the town with …（原著主张）",
"“自己缝一件衣服要十天、三天的粮换一件”是创作示例，具体天数非原著。小满台词是剧情化的说法。",
"“农业先得有剩余，城市才长得起来”是现代解释，非原著用词。",
"略：#17 …（篇幅）；#26 古埃及、中国、印度斯坦（合规：点名国家作比较）。"
```
开头那句如果是大家常说的话，facts 里写“当代说法，非原著”，并写明不对今天的什么下判断。

## 五、片长估算（写完就算）
- 云舟 2.0 语速 24：约每分钟 350 字（含 ⏸）；开头场景 `rate` 14 会慢一点
- 用 `工具\est_length.py epXX`（拿已经配过音的一集做基准估算，并数“书里”“斯密”）
- **4:00–5:00**（10-30 用户：“视频不必再压缩了，还是回到我们之前的 4–5 分钟”；3 分钟试验和 3:45–4:30 作废）。超了先删虚词、把画面上已有的数字从口播里拿掉、去掉多余的“书里说”，**不砍原著论证链**

## 六、改剧本
- 只有改过的句子会重新配音；只加减 ⏸ 不会
- 插句会让后面句号错位 → 画面代码里 `L.s(i)`、`W(i, "词")` 要跟着改；新内容尽量做成新场景
- 改之前旧版留着：重出片时旧成片会自动进 `_历史版本`；大改的剧本可以另存 `script_v1_说明.json`
