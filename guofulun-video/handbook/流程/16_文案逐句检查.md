# 16 · 文案逐句检查（配音前的最后一道关）

> **【必须】【10-24 用户要求】表达不通顺、表述错误的句子一律禁止进配音。**
> 背景：EP12“租子”、EP13“金银又轻又值钱”、EP14“看它多得比想要它的人快不快”、EP15 封面“为啥有的越买越贵”都是剧本阶段没拦住、成片后才被用户指出的；第二篇起外部复核又查出过“挥霍者”“宴席可能一半”“节俭的倾向”“最多四五镑”等和原文不符的说法（EP20、EP21）。

---

## 一、做法
1. 把每一句旁白、角色台词、**画面上的大字、卡片、结论章、公式卡、三格标签**都单独拿出来
2. 念出声（普通人的语速）
3. 按下面 8 条逐条打勾；有一条不过就改，改完再念
4. 跑一遍 human-writing 的检查脚本（查口头禅、黑话、模型腔），把剧本所有句子存成一个文本文件后：
   ```
   python "%USERPROFILE%\.claude\skills\human-writing\scripts\check_prose.py" <文本文件>
   ```
   报警都要看；EP23 审核记录写的是“check_prose.py 全部 0”
5. 结果写进 `审核记录.md` 第 1 关“G 逐句”一行：**列出改了哪几句、原句 → 新句、为什么**

## 二、8 条标准

| # | 标准 | 不过关的例子 → 改法 |
|---|---|---|
| 1 | **一听就懂**：听一遍能复述；不需要换算、比较、倒推 | “看它多得比想要它的人快不快” → “钱多了、东西也多了，钱不贬值；光钱多、东西没多，钱才贬值” |
| 2 | **主语清楚**：谁做了什么一清二楚；同一个东西全片一个叫法 | “为啥有的越买越贵”→“为什么肉越来越贵，手表却越来越便宜？”；“北美那些殖民地……阿禾攒下一点钱”→“要是在北美那些殖民地……”（说清是假设） |
| 3 | **口语、不拗口**：无翻译腔、书面腔、四字堆砌、连续三个“的”；三格标签念一遍要顺 | “省下去哪了”（会读成“省（下去）哪了”）→“省下的去哪了” |
| 4 | **用词准确**：词义和事实对得上；单位用原文的 | “租子”→ 房租 / 地租 / 租金；“镇子刚开张”→“镇子刚有的时候”（镇子不说开张） |
| 5 | **常识核对** | “金银又轻” → “一小块就很值钱” |
| 6 | **因果不过度**：原文的限定词保留；原著没说的因果不加 | “跟钱多钱少没关系”“利息降说明本钱多”（EP21 说过头）→ 加上原文的条件；“最多多出二十四倍”→“有时能多出”（EP22） |
| 7 | **数字可查**：每个数在知识卡有原文出处；画面上不出现原著没有的数（包括动画过渡里的中间值）；创作示例的数在 facts 标明 | “十天、三天”标创作示例；金银算例少报数、补“假设”（EP21） |
| 8 | **前后一致**：开头的问题、中间的结论、结尾的回答说同一件事；标题、封面、腰封、发布文案和片中一致 | 片中说“越买越贵”，封面不能写“增值”；三张封面腰封和口播同步改（EP22“最多”→“有时能”） |

## 三、顺手查
- 逻辑顺序：问题和答案之间不要插别的话
- 逻辑方向：有没有说反（EP15s“让卖肉的人不用找到正好缺肉的人”说反了）
- 角色问的问题，回答要直接（EP23 小雪问“镇子越大，乡下不就越吃亏？”，原稿答“正好相反”→ 改成“不会”，不翻案）
- 有没有让观众回答的话；有没有“我认为”“我觉得”；有没有“先猜一猜”
- “斯密”次数（≤2）、“书里”次数
- 有没有评价今天的政策、预测价格、制造恐慌

## 四、写进审核记录的格式
```markdown
| G 逐句 | 8 条 + human-writing | ✅ | check_prose.py 全部 0；改了 3 处：①“镇子刚开张”→“镇子刚有的时候”（镇子不说开张）②…… |
```
