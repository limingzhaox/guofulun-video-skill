# 21 · 出片

> 命令：`python produce.py epXX --skip-audio`（在 `D:\AI\短视频\studio` 下，**后台运行**，等完成通知）
> 集号可以带一个字母后缀：`ep06s`、`ep15s`；Remotion 作品 ID 是集号大写（`EP15S`）。

## 一、它依次做什么
1. （不加 `--skip-audio` 时）先跑 `gen_assets.py`
2. `npx tsc --noEmit -p .`（**整个 src 一起查**）
3. `npx remotion render <入口> EPXX` 用本机 Edge 渲染（crf 18）
4. 两遍线性响度标准化 -14 LUFS + 限幅 → **`EPXX_成片.mp4`**
5. 原始渲染留在 `studio\_cache\epXX_render.mp4`（`--remaster` 用）
6. 导出 `字幕.srt`、`剧本.md`（含事实核查）、复制 `知识卡.md`
7. 渲染 **`EPXX_封面.png`**（9:16）、**`EPXX_封面_3比4.png`**（发布用）、**`EPXX_封面_横屏.png`**（4:3，`index.ts` 导出了 `CoverWide` 才有）
8. 没有 `EPXX_发布文案.md` 时从模板复制一份（已有的不覆盖）
9. 覆盖前的旧成片、旧封面自动移进 `_历史版本\`（文件名带原修改时间；旧的无集号文件也一起归档）——**这就是 A/B 测试用的旧版**

产物文件夹 = `script.json` 的 `meta.folder`（命名见 `模板\归档命名规范.md`：`EPnn_第X篇第Y章_主题`，主题 2–6 字，不带日期版本号括号空格；发布过的不改名）。

## 二、参数
| 参数 | 用途 |
|---|---|
| `--skip-audio` | 最常用：剧本没改或已单独配过音 |
| `--cover-only` | 只重出三张封面 |
| `--remaster` | 只重做响度和限幅（不重渲染） |
| `--rename` | 不出片，只把文件夹里旧的无集号文件改成带集号的名字（EP17 及以前已发布的不回改） |
| `--entry=src/solo51.tsx` | 换一个只登记本集的渲染入口：**别的对话正在做的集出错、总入口打包失败时用**（EP51 有 `src\solo51.tsx`；别的集可以照它写一个只 import 本集的入口） |

## 三、耗时
3 分钟的片约 5–7 分钟，4 分钟约 6–8 分钟，10 分钟约 12–15 分钟。日志重定向到文件：
```
python produce.py epXX --skip-audio *> "$env:TEMP\epXX_prod.log"
```

## 四、出片后必做
1. 日志最后一行是“完成：……”
2. 抽帧两轮、核开头时间线（`20`）
3. 测响度（`工具\loudness.py`）
4. 看三张封面
5. 把 `studio\episodes\epXX\审核记录.md` 复制到成片文件夹
6. 文件夹自查 8 件套：`EPnn_成片` / 三张 `EPnn_封面` / `字幕.srt` / `剧本.md` / `知识卡.md` / `审核记录.md` / `EPnn_发布文案.md`

## 五、【坑】
- 整个 `src` 一起编译：别的对话正在改的集（或心理号 `src\xl*\`）出错会让出片失败——**不要去改别人的文件**；用 `--entry=` 只编本集，或成片已出时只补封面
- PowerShell 读 UTF-8 JSON 会乱码 → 用 Python 读
- 出片中途会话断了：重跑即可（旧成片自动进 `_历史版本`）
- 对外发文件（给别人、别的平台）才用全名 `国富论EPnn_主题_用途_vX_YYYYMMDD.mp4`；文件夹里保持短名
