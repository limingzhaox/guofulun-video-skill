# 19 · 分镜与画面

> **★ 先读 `画风\60_画风总纲.md`**：画面的确切数值（配色、字号、坐标、动画帧数）、参考截图（`画风\61_参考画面\`）、能直接跑的源码和人物图（`画风\63_画面源码_最小工程\`）都在那一册。本章讲分镜怎么排、每个镜头要什么。
> 代码写法见 `技术\44`；组件见 `技术\43`、`画风\62`。**画面是用户最常打回的部分**，标【坑】的都被打回过。
> 第二篇（EP16–）现行画风 = **★ 10-26 融合版**：第一篇的书页外框 + 纸色虚化小镇 + v16 彩铅人物和道具当插图。样板：EP23（最新）、EP17（融合版第一集）。

## 二、版式（EP25 起 `TOPS`；EP23、EP24 已重出；EP22 及以前整组低约 54px）
```
y 0–120      被抖音状态栏和“关注/推荐”挡住
y 104        页眉（目录标签）             ← Episode headerY={TOPS.header}
y 186–244    PartBar 三格（高 58、字号 28）← PartBar top={TOPS.bar}
y 272        顶部关键词 Keyword（≤8 字，不复读字幕）
y 284        结论章 Verdict
y 400–1262   画面（人物脚底 FOOT ≈ 1262）
y ≈1338      字幕
```
【坑】10-31 用户看 EP22 手机截图：页眉和三格“往上靠，现在会挤占中间的画面”→ 整组上移约 54px；页眉不要再往上（抖音顶部导航约盖到 y≈120）。
- 前排相邻两人留 ≥15px；人物身高：单人 600–660，两人 520–620，后排手艺人约 222
- 标签放头顶上方或脚边，不压身体；气泡、读数不出画面（x 60–1020）

## 三、开头画面（★★★★★，照 EP25 `SHook`，截图 `画风\61_参考画面\EP25_01`–`07`）
- **第 0 帧只出一行大字**（本集问题的短版，≤12 字，74 号宋体，y≈270，5px 纸色描边，6 帧淡入），背景纸色虚化小镇；第 2 帧“叮”
- **第一句念到哪个词出哪样东西**：场景、道具、标签、箭头、问号一样样弹出（锚点词前 4–10 帧），关键词念到变朱砂红；每样配一个音效。EP25：“欧洲”→庄园和田、“农奴”→农夫走出来、“攒了钱”→钱袋、“被抓回去”→老爷头像 +“！”、“带进城”→城墙砌起、农夫往城门走
- **【坑】10-30 EP24 第一版第一句 4 秒里只有居中两行字**，用户：“这块没有动画搞错了……23 集就有的，字头图案的风格也加回去”
- **【坑】第一幕真实截图风、扁平线稿风都被否**（“字体、配色、间距、配图风格都很不搭”），第一幕必须和正片同一套（彩铅道具：crayon 滤镜抖线、`#3E2A20` 手绘线、彩铅填色、`wrect` 手绘矩形）
- **第一句念完**：本集角色放大入场（540 高，头顶名签、汗滴 / “！”），说出损失 / 委屈；顶部关键词换成提炼词
- **第 3 句**：红框“《国富论》”签 + 道具跟着词出
- **三问**：`Card` 三张问句卡（问题 + 下一行概念名），间隔 ≤1.5 秒弹出，第三张红边放大；`PartBar` 从这句起出现；**不加“出人意料”横幅或小字**

## 四、每个镜头必须有（10-24、10-26 两次打回）
| 必须 | 说明 |
|---|---|
| 相关的角色 | 只放和这句话关系最大的一两个人（正在说话的、正在做旁白说的事的）；不凑数站桩；放大 |
| 一个在动的东西 | 主道具之外至少再有一个在动的人物或一组相关东西（【坑】只有一辆车的镜头“太单调了”→ `CartScene`：阿禾推车、街坊等货、念到“货”时货飞到街坊手里） |
| 讲什么画什么 | 道具跟着台词出现（粮袋、衣服、金币、马车、船、账本……），讲道理的图放 `Card` 上 |
| 表情和反应 | `jolts`（吓一跳）、`Emote`（！？♪ 汗 星星）、跳、点头摇头、脸红 |
| “第 X 步”开场 | 对比道具 + 一个角色 + 问号 |
| **演示动画（★★★★★）** | **每一步至少 2 个**“把道理演出来”的小动画，一句话说得清怎么动、1–2 秒、跟着口播的词起（关卡抬起、城墙砌起、契约划掉改写盖章、跷跷板翘起、锁链断开……）。【坑】10-30 用户看完 EP23：“全集都是几个模块没有变化”——卡片、标签、田、小镇、飞来飞去的钱只能当底子。现成的演示动画道具见 `画风\62` 第三节 |
| 讲“出国” | 画出本国和港口的船 |

**画面减法**：后排人物只在念到他那一行时出现、虚化；不放彩旗、花丛、栅栏这类纯装饰；墙上不摆书架窗户。

## 五、一句一个画面，画面跟着嘴走
- 一句话里分镜头用 `Shot`（前后 8 帧叠化）；镜头基本静止，不乱推乱跳
- 元素在锚点词前 4–10 帧出现（`useWordAt`），**不能晚于旁白**；锚点词在这句里要唯一（`工具\anchors_check.py` 查）
- 顶部关键词不能和同一时刻字幕一字不差（`工具\kwdup.py` 查；EP18 自查出约 15 处，用提炼词、数字或原话替换）
- 第一部分结尾回扣开头同一个画面；结尾再回一次（最多两次）

## 六、转场、镜头、冷节拍
- 转场：page（翻页）≥2 处、ink（墨迹）≥2 处，fade 补充；开头场景 `enter="none"`
- 镜头：`Shell cam` 基本 `still`，靠 `Shot` 切镜；需要推拉用 `Camera`
- 至少一处冷节拍：`PaperTown dusk`；暗场 `dark` + `hush` 留给最大的翻转

## 七、角色能做和不能做（`v16/Sprite.tsx`）
- 能：呼吸、眨眼、说话张嘴（`useTalk` 按配音逐字）、走路颠步、转身（换视角 + 压扁回弹）、跳、点头、摇头、吓一跳（`jolts`）、脸红、头顶符号、脚下影子
- 不能：抬手、指、拿东西、换表情 → 用道具自己动、标签、镜头补；真要先请用户出姿势图
- 职业人物和猫只有朝右的视角，**不镜像**；猫狗不眨眼
- 张嘴要先盖住原画嘴线（`mouth.bg`）；新角色接入流程见 `技术\40`
- 光晕一律画在人身后、暖金色（盖在脸上会把肤色染黄）；肤色要有血色（小满用 `xiaoman3`）

## 八、数字和读数
- 画面上每个数都要在原著里有，或标明创作示例
- 读数分段跳（`f < 某帧 ? 4 : 2`），**不显示动画过渡中间值**（EP14 天平“3.1 盎司”）
- 原著没给的数不画；外部复核要求“少报数”的地方只留在画面上（EP22 烟草数字）

## 九、字幕（`Episode.tsx` 自动）
- 一段话（标点隔开）整段同屏：≤14 字正常、15–20 字缩字、>20 字同屏两行
- 角色台词字幕前挂小头像（`Video.tsx` 的 `badge` + `Avatar16`）

## 十、公式卡和结尾
- 公式卡：红底标题条 + 3 行大字（一件一行，以书里的说法开头），不加箭头副行，不叠人物
- 旁白念完只停 2–3 秒；“下一集：……”预告字放卡外，念完就淡出（用词锚点，不要用 `L.e(0)`，它算上了句尾 ⏸）
- 结尾回扣开头画面 + 回顾句点出书里的专有名词，卡片和公式卡同步写上
