# 20 · 抽帧检查与修改

> AI 看不了视频，只能看图片：质检 = **按句抽帧拼联系表 + 关键句全尺寸静帧，逐张看**。

## 一、四种检查
| 时机 | 做法 | 看什么 |
|---|---|---|
| 写完代码 | `python 工具\anchors_check.py epXX` | 每个 `W(i, "词")` 的词在第 i 句里有没有、是否重复（EP23 审核：59 个锚点全部在台词里） |
| 写完代码 | `python 工具\kwdup.py epXX` | 顶部关键词 `Keyword` 有没有和同场景字幕一字不差（EP23 查出 3 处） |
| 出片前 | `python review.py epXX` → `studio\_review\epXX_总览.png`（每句 75% 处） + 关键句全尺寸静帧 | 版式、重叠、晚于旁白 |
| 出片后 | `python 工具\frames.py <EPXX_成片.mp4> <timeline.json> <输出目录> 0.8`，再抽一轮 0.92 或 0.55；场景交接处 ±9 帧单独抽 | 全部 |

全尺寸静帧（看小字、表情）：`npx remotion still src/index.ts EPXX <输出.png> --frame=<帧号> --browser-executable="C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"`
中间物放 `D:\AI\短视频\抖音账号\视频矫正\_work\EPnn_主题\` 或临时文件夹，结论写回审核记录。

## 二、开头时间线核对（★★★★，写进审核记录）
从 `timeline.json` 读出并写下：第一句几秒念完（≤2.5）、角色几秒出场（2.5–6）、第 3 句书名几秒、三问一句几秒（≤6）、几秒进故事（≤18）、前 30 秒的顶嘴在几秒。例（EP23）：第一句 2.3 秒、2.7 秒农夫阿禾顶嘴、7.4 秒《国富论》、三问 5.1 秒、18.1 秒进故事。

## 三、逐张看什么
1. 字幕：完整一段、无错字
2. 文字：不折行、不出画面、不互相压；结论章、三格标签完整
3. 画面和这句台词对得上；元素没有晚于旁白
4. 角色：只放相关的、够大、有表情 / 动作；没有凑数站桩；配色不融进背景；嘴线盖干净
5. 每个镜头主道具之外还有一个在动的东西（不单调）
6. 数字：和原著一致，没有过渡中间值
7. `PartBar`：讲到哪格涂到哪格、结论时打勾；“出人意料”横幅没有出现
8. 冷节拍在不在；回到开头的画面最多两次
9. 公式卡：3 行、干净、念完停 2–3 秒、预告字淡出
10. 封面三张（见 `22`）

## 四、常见修法
| 问题 | 修法（EP23 实例） |
|---|---|
| 开场的图太小、压在底部 | 放大到画面中下部、箭头加粗（开头、第一步结尾、结尾共用） |
| 标签贴着招牌 | 上移 |
| 名签字太小 | 26 → 30 号 |
| 封面角色挡住道具 | 挪开、重出三张封面 |
| 关键词复读字幕 | 换提炼词：“谁养活谁？”→“城里 vs 乡下” |
| 画面单调 | 加一个在动的人或一组相关东西 |
| 元素晚于旁白 | 锚点改到句首附近的词，或提前 4–10 帧 |

修完重新出片，**再抽一轮**，直到一轮里没有问题；改了几处写进审核记录“画面对台词”一行。
