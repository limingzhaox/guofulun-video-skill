# 14 · 情节与人物设计（先设计，再写剧本）

> 设计结果写进知识卡“故事设计”一节，“开拍前五问”写进审核记录。
> 现行骨架 = **★★★ 一集一个问题**（10-28，EP20 起）+ **★★★★ 开头**（10-29）。依据：用户 10-28 给的系列定位复盘——**场景（进得来）→ 机制（看得懂）→ 概念（记得住）→ 适用条件（靠得住）**。

---

## 一、骨架（第二篇，一集约 3–4 分钟）

```
开头（0–18 秒）：观众心里那句话 → 本集角色说损失 → “《国富论》里说……”半张牌 → 三问（同一个问题的三步）
第一步（问题①）：同一个案例 → 原著论证 → 角色真异议 → 解释换方向 → 画面结论章 + 口播一句结论
               第一步结尾回扣开头同一个画面，砸出金句（第二钩）
第二步（问题②）：同上；一处冷节拍（PaperTown dusk）
第三步（边界）：“……还成立吗 / 会怎样？”——旧答案碰到边界（EP23：地便宜的地方，城还长得大吗？）
结尾：回到开头画面 → 正面回答开头的问题 → 点名概念（书里叫法 + “今天常说……”）→ 别套错（一句适用条件）
     → “下次……先问一句：……？” → 公式卡（3 行，念完停 2–3 秒）→ 用下一集的问题预告
```

## 二、七条设计规矩（★★★）

1. **一集只解决一个问题**：开头那个问题就是全片唯一的问题；顶部三格 = 同一个问题的三步（EP20：省下的钱去哪 / 花掉的不也养人 / 人人都省会怎样；EP23：城里拿什么换 / 先有乡下才有城 / 地便宜城会怎样），每格 ≤7 字、念一遍要顺（EP17 第三格“省下去哪了”被读成“省（下去）哪了”，改成“省下的去哪了”）
2. **第三步是边界问题**，不说“最出人意料的是第三件”——中段的吸引力来自旧答案碰到边界，不靠“更可怕的在后面”
3. **三问卡讲清概念**：每张卡 = 一句完整的问题 + 下面一行概念名（“书里叫‘节俭’”“后来叫‘节俭悖论’”），口播只念问题（10-28 用户：只剩悬念观众猜不透）
4. **同一个案例从头用到尾、少换比喻**：一集一组人物、一个场景，变的只是金额、时间、钱的去向（复盘批评 EP18、EP19 比喻太多：房子、水塘、抽屉、大路、车道、防火墙、天平）
5. **中段用真不服气的异议推进**：每 30–50 秒一个角色说出观众心里的反驳（“那我花掉的不也养活了人？”“粮都让城里人吃了，农夫不亏吗？”），**它要改变解释的方向**，不是递话
6. **点名一个概念**：书里的叫法 + 今天的术语，口播第一次说时讲明“今天常说 / 后来的经济学家说”，不把现代术语说成斯密原话（EP23：“财富的自然进步”｜今天常说“农业先得有剩余，城市才长得起来”）
7. **结尾交代适用条件**：一句“别套错”（EP23：“书里说的是靠人力种地、靠马车运粮的年代。今天一个人能种几百亩地，城乡怎么分工，不能拿这一集直接套。”）；回顾压成一句点名概念，不再三件逐条复述

## 三、开拍前五问（写进审核记录第 1 关）
1. 标题承诺具体吗？结尾正面回答了吗？
2. 前 20 秒看到核心矛盾了吗？
3. 中段每一段都改变理解了吗？
4. 观众能叫出一个概念并举例吗？
5. 结尾有没有交代不能直接套用的条件？

## 四、人味（★★★★ + 好视频六个特征）
- 第 2.5–6 秒角色说出具体的损失 / 委屈（先给结局后讲过程）
- 前 30 秒至少一次反问或顶嘴；像聊天不像上课
- 关键节拍人物有表情和小动作：跳一下、吓一跳、点头摇头、脸红、头顶符号（！？♪ 汗 星星），人物在画面里够大
- 至少一处生活里真实的小场景
- 不编真人真事（不写“我楼下开了 20 年的早餐店老板”）；观众要知道这是故事里的人

- 角色只能做：呼吸、眨眼、说话张嘴、走路、转身（换视角）、跳、点头、摇头、吓一跳、脸红、头顶符号；**做不到抬手、指东西、拿东西、换表情**（要这些先请用户出姿势图），用道具自己动、标签、镜头来补
- 职业人物和猫只有朝右的视角，**不镜像**
- 一个镜头只放和这句话关系最大的一两个人；配色要和米黄背景拉开
- 第二篇后面可能缺的：地主（v16 版）、长子、农奴 / 佃农、领主、市民、水手 / 船主、士兵、仆人、乐师——**到那一集写开头候选时一起提**

## 六、颜色、串场、冷节拍
- 三步配色压低饱和：赭金 `#C3923F`、墨青 `#3F6E73`、橄榄绿 `#5E7F4A`；强调色只用朱砂红 `C.red`；正文墨色 `C.ink`
- 串场画面：开头那张图（EP23 的“田 ⇄ 镇子”`CountryTown`）在第一步结尾、结尾再出现（回到开头最多两次）
