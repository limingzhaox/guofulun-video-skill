> **★ 2026-10-30 更新（用户定“以后都这样”，以 `CLAUDE.md` 最上面 ★★★★★ 为准）**：①第一句用“你有没有想过，＋本集问题”的完整问句（约 4 秒，开头语速 14），进故事放宽到 19–20 秒；②第 0 帧只出一行大字，场景、道具、标签、箭头跟着口播念到的词再出来；③封面换回书海报版式 `<BookPoster {...P} bookS={0.8} />`（书居中、标题在下，不用“问题在上”版式，封面不放本集角色）。④片长回到 4–5 分钟，不再压缩（10-30 用户），审核按 4:00–5:00 算。样板 EP23 第三版。

> **【先问用户】【必须】开头写好候选后停下来，等用户选定才往下做。**（10-22 用户：“开头确定好了给我选好之后再开始视频制作，不要直接做。”）
> 现行规则 = **★★★★★ 10-30**（第一句“你有没有想过，＋本集问题”、第 0 帧一行大字、东西跟着嘴出）+ **★★★★ 10-29**（本集角色说损失、第 3 句报书名、三问 ≤6 秒）+ **★★ 10-27**（声音不落后画面、半张牌）+ **★★★ 10-28**（三问卡 = 同一个问题的三步，写概念名）。作废的：“前 15 秒不报书名”“整句结论 + 路线图”“第一句 ≤2.5 秒”“不加‘你有没有想过’”（见 `规范\30`）。
> 10-29 的理由（开头这道门要改）仍然成立；10-30 用户看完 EP23 第三版后定“以后都这样”：第一句用完整的问题，比 2.5 秒的短句更说得清这一集问什么。
> 为什么：10-29 后台数据平均播放只有 14–18 秒、2 秒跳出 32–45%。对比时间线：历史最高的 EP10 第一句“钱多、事少、离家近。”**2.1 秒、7 个字、是观众自己的处境**；EP19–21 第一句 3–5 秒、18–30 个字、问的是书里和国家的问题，三问卡卡在第 13–19 秒——正是人走的地方。**留下来的人认可内容，要改的是开头这道门。**

## 一、开头的时间线（照 EP25 / EP24 / EP23 第三版；画面截图 `画风\61_参考画面\EP25_01`–`07`）

| 时间 | 要完成 | 画面 | 实例 |
|---|---|---|---|
| 0–约 4 秒 | **第一句**：“你有没有想过，＋本集那个问题”的完整问句（开头语速 14）；用户也定过“你知道吗，……”陈述句（EP25），但“你知道吗”和“为什么……？”不能叠在一句里 | **第 0 帧只出一行大字**（本集问题的短版，≤12 字，74 号宋体，y≈270），**念到哪个词出哪样东西**（场景、道具、标签、箭头、问号）；第 2–3 帧“叮”；**不要第一句念完前空屏** | EP23：“你有没有想过，城里人和乡下人，到底谁养活了谁？”大字“城里乡下，谁养活了谁？”；念到“城里人”出镇子、“乡下人”出田、“到底”出箭头、“谁养活了谁”出问号并变红 |
| 约 4–12 秒 | **本集角色说出具体的损失、委屈或怀疑**（先给结局后讲过程）；不编真人真事 | 角色放大入场（540 高）、头顶名签、汗滴 / “！”；道具跟着说的话动 | EP23 农夫 4.2 秒开口；EP25 农夫：“这点钱让老爷知道了，就归他了……” |
| 第 3 句 | **报书名、给半张牌**：“《国富论》里说，……”，不说为什么 | 红框“《国富论》”签 + 道具跟着词出 | EP25：“《国富论》里说，那时候乡下归老爷管……城里才安全。” |
| ≤6 秒内 | **三问**：口播合成一句，三张卡间隔 ≤1.5 秒弹出，卡 = 问题 + 下一行概念名，第三张红边放大；顶部三格进度从这句起出现 | 三问卡 + `PartBar` | EP25：“城里人一开始就自由吗？城里的自由是怎么换来的？城里富了，乡下跟着富了吗？” |

| ≤30 秒 | 至少一次角色**反问或顶嘴**（像聊天，不像上课） | — | EP10：“我们手慢了？”“为什么？” |

开头不点名洛克、孟德斯鸠这类大人物，用“好多大学者都以为”；不频繁用“你以为……其实……”（偶尔一次可以）。

## 二、写候选的步骤

1. **先写翻译**：每个候选都先写“书里的问题 → 观众心里那句话”（`审核清单.md` F 节要求）
2. 写 3–4 个候选，**每个写到三问卡**（4–5 句，都是将来真要配音的原话），标出：第一句字数和估计秒数、大字写什么、2.5–6 秒哪个角色说什么、三问三步各叫什么（三格 ≤7 字）
3. **列这集要的角色**，对照仓库清单（`模板\v16风格定稿_20261025\角色清单.png`）；缺的在这里一起告诉用户
4. 按下面的自查表过一遍再发
5. 写一句推荐理由；有不推荐的也说为什么（EP23：“接 EP22 预告”那个没推荐，因为这一章只说欧洲把顺序倒过来了、没说为什么）

## 三、自查表（每个候选都过）
- [ ] 第一句是一个完整的问题（“你有没有想过，……？”），话说完整：谁、做什么、结果怎样，不靠上下文就懂；约 4 秒
- [ ] 一句只用一种语气（要问就只问，要讲就只讲）
- [ ] 第 0 帧大字 ≤12 字，是本集问题的短版；写清第一句里**哪个词出哪样东西**（至少 3–4 样）
- [ ] 约 4–12 秒有本集角色说出具体损失 / 委屈，是故事里的人
- [ ] 第 3 句“《国富论》里说”+ 半张牌，不说为什么
- [ ] 三问一句 ≤6 秒，是同一个问题的三步，第三步是边界问题
- [ ] 19–20 秒进故事；前 30 秒有顶嘴
- [ ] 不假结论、不制造恐慌、不编真人、不评价今天的政策；不要求观众回答
- [ ] 能在结尾回到这个开头画面

## 四、交给用户的格式

> 选项**写在消息正文里**（提问工具的预览栏用户看不到）。

```
EP24（第三篇第 2 章）开头给你 4 个候选，每个写到三问卡：

**A.（推荐）** 书里的问题：…… → 观众心里那句话：……
1. 你有没有想过，……？（第一句，约 4 秒；大字“……”；念到“……”出……、念到“……”出……）
2. 地主：……（约 4–12 秒，说具体的损失）
3. 《国富论》里说，……
4. ……？……？……？（三问，三格：……／……／……）
需要的角色：地主（有）、长子（仓库没有，要出图）……

**B.** ……

我推荐 A，因为……。你选一个，或者告诉我哪句要改。
```

## 五、用户回复后
| 用户的回复 | 怎么做 |
|---|---|
| “就用 A” | 原样定稿，**当场写进知识卡和审核记录**（别的对话才看得到） |
| 改了几个字 / 自己写一段 | 用用户的字为主，只修通顺和事实错误，说明理由，再确认一次 |
| “这句什么意思？” | 说明读不懂 → 一定要改成大白话 |
| 质疑事实 | 立刻核原文；错了认、改，写进 `审核清单.md` F 节 |
| “第一句要说清‘我的钱’” | 照改（EP21 第四版就是这样从“存钱，怎么越来越不划算了？”改成“你存银行的钱，利息怎么越来越少？”） |

**【坑】用户定的开头，后面任何诊断都不要擅自换掉**（10-29 EP22：用户定的是“做买卖，跑外贸才赚大钱？”，外部诊断后 AI 换成“商人赚得多，就更养本国人？”，被用户指出“没有同步好记忆”）。要动先问。

## 六、配音和画面的配合
- 开头场景单独写 `context`：“像跟朋友聊天时，随口问出一个大家都好奇的问题，带一点笑意和好奇，自然、从容、不着急”；开头场景 `"rate": 14`
- 第 0 帧只有一行宋体大字（y≈270、72–76 号、5px 纸色描边），背景是纸色虚化小镇；场景、道具、标签、箭头、问号**跟着口播念到的词**一样样出来（元素在锚点词前 4–10 帧弹出），关键词念到变朱砂红；“叮”在第 2–3 帧
- 本集角色在第一句念完后放大出场；人物出场前画面上也要有东西在动（10-30 EP24 第一版第一句 4 秒里只有居中两行字，用户：“这块没有动画搞错了……23 集就有的，字头图案的风格也加回去”）
