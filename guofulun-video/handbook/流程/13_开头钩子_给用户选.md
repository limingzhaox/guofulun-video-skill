# 13 · 开头：写候选，交给用户挑（10-29 版）

> **【先问用户】【必须】开头写好候选后停下来，等用户选定才往下做。**（10-22 用户：“开头确定好了给我选好之后再开始视频制作，不要直接做。”）
> 现行规则 = **★★★★ 10-29**（从观众情绪开口）+ **★★ 10-27**（一个钩子一句话、声音不落后画面、半张牌）+ **★★★ 10-28**（三问卡 = 同一个问题的三步，写概念名）。旧的“前 15 秒不报书名”“整句结论 + 路线图”“你有没有想过”都已作废（见 `规范\30`）。
> 为什么：10-29 后台数据平均播放只有 14–18 秒、2 秒跳出 32–45%。对比时间线：历史最高的 EP10 第一句“钱多、事少、离家近。”**2.1 秒、7 个字、是观众自己的处境**；EP19–21 第一句 3–5 秒、18–30 个字、问的是书里和国家的问题，三问卡卡在第 13–19 秒——正是人走的地方。**留下来的人认可内容，要改的是开头这道门。**

---

## 一、开头的时间线（照 EP23 / EP21 第四版）

| 时间 | 要完成 | 画面 | EP23 实例 |
|---|---|---|---|
| 0–2.5 秒 | **观众心里那句话**：第一屏大字 ≤12 字，口播第一句 ≤2.5 秒；假设类加“假如” | 第 0 帧宋体大字（只出已经念到的）+ 一个和问题直接相关的彩铅物件；第 2–3 帧“叮” | “城里人和乡下人，谁养活谁？”（2.3 秒；大字“城里乡下，谁养活谁？”9 字） |
| 2.5–6 秒 | **本集角色说出具体的损失、委屈或怀疑**（先给结局后讲过程）；不编真人真事 | 角色放大入场，头顶“！” | 农夫：“全城吃的粮，都是我种的。”阿禾：“你身上这件衣服，可是我做的。” |
| 第 3 句 | **报书名、给半张牌**：“《国富论》里说，……”，不说为什么 | 物件动起来 + 红章 | “《国富论》里说，城里吃的用的全靠乡下，可城里挣的，不是从乡下抢来的。” |
| ≤6 秒内 | **三问**：口播合成一句，三张卡间隔 ≤1.5 秒弹出，卡 = 问题 + 下一行概念名，第三张红边放大；顶部三格进度从这句起出现 | `ThreeRows` 卡 + `PartBar` | “城里拿什么换乡下的粮？为什么先有乡下才有城？地便宜的地方，城还长得大吗？” |
| ≤18 秒 | **进故事**：人物带着冲突直接出场，不铺垫背景、不说“上一集” | — | 18.1 秒“镇子刚有的时候……” |
| ≤30 秒 | 至少一次角色**反问或顶嘴**（像聊天，不像上课） | — | 开头两人顶嘴 + 第 32 秒小满“农夫不亏吗？” |

开头不点名洛克、孟德斯鸠这类大人物，用“好多大学者都以为”；不频繁用“你以为……其实……”（偶尔一次可以）。

## 二、写候选的步骤

1. **先写翻译**：每个候选都先写“书里的问题 → 观众心里那句话”（`审核清单.md` F 节要求）
2. 写 3–4 个候选，**每个写到三问卡**（4–5 句，都是将来真要配音的原话），标出：第一句字数和估计秒数、大字写什么、2.5–6 秒哪个角色说什么、三问三步各叫什么（三格 ≤7 字）
3. **列这集要的角色**，对照仓库清单（`模板\v16风格定稿_20261025\角色清单.png`）；缺的在这里一起告诉用户
4. 按下面的自查表过一遍再发
5. 写一句推荐理由；有不推荐的也说为什么（EP23：“接 EP22 预告”那个没推荐，因为这一章只说欧洲把顺序倒过来了、没说为什么）

## 三、自查表（每个候选都过）
- [ ] 第一句是观众心里那句话（自己的处境 / 情绪），不是书里或国家的问题
- [ ] 第一屏大字 ≤12 字；口播第一句 ≤2.5 秒（约 9–10 个字以内；EP21 第四版“你存银行的钱，利息怎么越来越少？”2.56 秒）
- [ ] 话说完整：谁、做什么、结果怎样，不靠上下文就懂
- [ ] 2.5–6 秒有本集角色说出具体损失 / 委屈，是故事里的人
- [ ] 第 3 句“《国富论》里说”+ 半张牌，不说为什么
- [ ] 三问一句 ≤6 秒，是同一个问题的三步，第三步是边界问题
- [ ] 第 18 秒前进故事；前 30 秒有顶嘴
- [ ] 不假结论、不制造恐慌、不编真人、不评价今天的政策；不要求观众回答
- [ ] 能在结尾回到这个开头画面

## 四、交给用户的格式

> 选项**写在消息正文里**（提问工具的预览栏用户看不到）。

```
EP24（第三篇第 2 章）开头给你 4 个候选，每个写到三问卡：

**A.（推荐）** 书里的问题：…… → 观众心里那句话：……
1. ……（第一句，约 2.3 秒；大字“……”）
2. 地主：……（2.5–6 秒，说具体的损失）
3. 《国富论》里说，……
4. ……？……？……？（三问，三格：……／……／……）
需要的角色：地主（有）、长子（仓库没有，要出图）……

**B.** ……

我推荐 A，因为……。你选一个，或者告诉我哪句要改。
```

## 五、用户回复后
| 用户的回复 | 怎么做 |
|---|---|
| “就用 A” | 原样定稿，**当场写进知识卡和审核记录**（别的对话才看得到） |
| 改了几个字 / 自己写一段 | 用用户的字为主，只修通顺和事实错误，说明理由，再确认一次 |
| “这句什么意思？” | 说明读不懂 → 一定要改成大白话 |
| 质疑事实 | 立刻核原文；错了认、改，写进 `审核清单.md` F 节 |
| “第一句要说清‘我的钱’” | 照改（EP21 第四版就是这样从“存钱，怎么越来越不划算了？”改成“你存银行的钱，利息怎么越来越少？”） |

**【坑】用户定的开头，后面任何诊断都不要擅自换掉**（10-29 EP22：用户定的是“做买卖，跑外贸才赚大钱？”，外部诊断后 AI 换成“商人赚得多，就更养本国人？”，被用户指出“没有同步好记忆”）。要动先问。

## 六、配音和画面的配合
- 开头场景单独写 `context`：“像跟朋友聊天时，说出一个大家常拌嘴的问题，带一点笑意和好奇，自然、从容、不着急”；开头场景 `"rate": 14`
- 第 0 帧不出卡通人物，只有宋体大字 + 彩铅物件（画法和正片道具一样）；角色在第 2.5 秒左右出场
- 屏幕大字只出已经念到的那句；“叮”卡在物件弹出那一帧（第 2–3 帧）
- 改开头重出：旧成片自动进 `_历史版本`，交付时提醒用户两版各投一条比 5 秒完播
