## 二、一集的关键数字（第二篇，10-29）

| 项目 | 标准 |
|---|---|
| 片长 | **4–5 分钟，不再压缩**（10-30 用户；审核按 4:00–5:00）；汇总 / 终章按用户要求 |
| 演示动画 | 每一步至少 2 个“把道理演出来”的小动画，写剧本时列进知识卡第五节（10-30） |
| 版式 | `TOPS`：页眉 104、三格 186、关键词 272、结论章 284（10-31，EP25 起） |
| 第一屏大字 | ≤12 字（只出已经念到的那句） |
| 口播第一句 | “你有没有想过，＋本集问题”的完整问句，约 4 秒（10-30）；一句只用一种语气 |
| 第 0 帧 | 只出一行大字（≤12 字），场景道具跟着念到的词出，不空屏 |
| 本集角色出场 | 第 2.5–6 秒，说具体的损失、委屈或怀疑 |
| 报书名 | 第 3 句“《国富论》里说，……”（给半张牌，不说为什么） |
| 三问卡 | 口播合成一句 ≤6 秒；三张卡间隔 ≤1.5 秒；每张 = 问题 + 下面一行概念名；第三张红边放大 |
| 进故事 | 第 19–20 秒 |
| 前 30 秒 | 至少一次角色反问或顶嘴 |
| 中段 | 每 30–50 秒一个角色说出真不服气的异议 |
| 每步结尾 | 画面结论章“第 X 步的结论”，口播一句普通话说结论 |
| 回到开头 | 最多两次：第一部分结尾、结尾 |
| 结尾 | 回到开头画面 → 回答问题 → 点名概念（书里叫法 + 今天说法）→ 别套错 → “下次……先问一句” → 公式卡 → 下集预告 |
| 公式卡 | 标题条 + 3 行，念完只停 2–3 秒（cta 句末 1 个 ⏸） |
| 顶部关键词 | ≤8 字，同一时刻和字幕不能一字不差 |
| “斯密” | 全片 ≤2 次（常常 0 次） |
| 字幕 | 一段话整段同屏 |
| 响度 | -14 LUFS，真峰值 ≤ -1 dBFS，P90−P10 ≤ 3 dB |
| 发布标题 | 3–4 个，每个 ≤20 字，主谓齐全，至少 1 个二选一 |
| 发布时间 | 晚上 20–22 点 |

## 三、四个“必须停下来问用户”的节点

1. **开头**（第 4–5 步）：3–4 个候选，等用户选。
2. **剧本**（第 7 步）：写完给用户过目，用户说可以再配音（第二篇起每集都这样）。
3. **新角色**：仓库里没有的角色先说要什么样，等用户用别的 AI 出图（`规范\31`）。
4. **方向性改动**：片长、画风、角色样子、封面版式、要不要重做已发布的集、外部复核意见里和用户已定规则冲突的部分。

其余步骤 AI 做完再交付，不要每一步都来问。
