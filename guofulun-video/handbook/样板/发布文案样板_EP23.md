## 这一集讲的经济学概念
```
概念：书里叫“城乡之间的大买卖”“财富的自然进步”｜今天常说“农业剩余”（现代解释）
核心：城里吃的用的全靠乡下，乡下的余粮也在城里找到买家，两边换着来都比自己动手划算。吃饭比享受在先，地里先有余粮，才养得起不种地的手艺人，这些粮也能从很远的地方运来。按自然的顺序，大部分本钱先去种地、再开作坊、最后做外贸；地便宜的地方，手艺人的余钱更愿意先买地。
别套错：这是斯密说的自然顺序，各国实际怎么走，还看土地、贸易和制度。
```

## 置顶评论
```
这一集的经济学：斯密说，每个文明社会最大的买卖是城里人和乡下人之间的买卖。城里吃的用的全靠乡下，可两边的好处是互相的：乡下人拿少得多的劳动换回多得多的东西，城里也是乡下多余粮食的市场。吃饭比享受在先，养活城里人的是乡下的余粮，这些粮不一定出在附近，也能从很远的地方运来。按自然的顺序，大部分本钱先去种地，再去开作坊，最后才做外贸。地便宜的地方（书里举北美殖民地），手艺人有了余钱更愿意先买地，给远处做货的作坊就开得晚；没有便宜地可买的地方，余钱才去开作坊。
出处：《国富论》第三篇第1章。“农业剩余”是今天的说法，不是斯密原话；“十天、三天活计”的账和阿禾去殖民地是举例，天数不是书里的；这是斯密说的自然顺序，各国实际怎么走还看土地、贸易和制度。农夫、阿禾、小满、小雪是动画人物。
下一集：按说先种地、再开厂、最后做外贸，近代欧洲为什么偏偏倒了过来，大片的地几百年都没好好种？
```
