> **为什么有这一册**：10-31 用户在另一台电脑上只拿技能做视频，画面“完全是不一样的呈现风格”。原因是以前的手册只写了“书页外框、纸色虚化小镇、彩铅人物”这些**名字**，画面的真身（配色值、字号、每样东西放在第几像素、人物图、彩铅抖线、动画节奏）都在 `studio` 工程的代码和图片里，换台电脑就没了，AI 只能自己猜。

## 一、一句话说清画风

**一页旧书上的彩铅插图。** 米黄纸色的底，后面是一座虚化的彩铅小镇（像相机浅景深），最上面是书页的页眉；前面站一两个 Q 版彩铅人物、摆几样彩铅道具，旁边贴宋体的小标签；底下一行宋体字幕，念到哪个字哪个字变黑。强调色只有一种朱砂红。

第一篇（EP01–EP15s）是纯“纸本编辑部”风（米白纸 + 墨色 + 朱砂红 + 扁平小人）；第二篇起（EP16–）是**融合版**：第一篇的书页外框 + v16 彩铅人物和道具当插图。EP16 单用卡通风发布后 2 秒跳出 45.35%、平均播放 10 秒，用户才定了融合（见 `61_参考画面\历史_*.jpg`）。

## 二、画布和安全区

- 竖屏 **1080 × 1920**，**30 fps**；封面另出 1080×1440（3:4）和 1440×1080（4:3 横屏）
- 抖音会挡住：顶部状态栏 + “关注 / 推荐”导航约到 **y≈120**；底部标题、按钮约从 **y≈1500** 起；右侧点赞栏约 x>960、y 900–1500
- 版式（EP25 起，`TOPS`；EP22 及以前整组低约 54px）：

      │        （抖音状态栏、导航，别放东西）        │

y 284 │        （结论时这里换成“第一步的结论”章）      │ ← 结论章 Verdict
y 400 │                                          │
      │     画面区：人物、道具、卡片（约 400–1262）    │

## 四、字体

- **全片只用思源宋体（Noto Serif SC）粗体**：900 做大字、标签、字幕、卡片，600 做页眉章节名。字体文件在 `63_…\public\fonts\serif-sc-600.woff2`、`serif-sc-900.woff2`（Google Fonts 的 Noto Serif SC，可商用）
- **不用**：站酷快乐体（EP16 用过，10-26 起作废）、思源黑体做字幕、手写体、78 号以上的大黑字（开头大字除外，见第十一节）

| 元素 | 字号 | 其他 |
|---|---|---|
| 开头第 0 帧大字 | 72–76（EP25 用 74） | 行距 1.4，墨色，5px 纸色描边，居中，y≈270 |
| 顶部关键词 `Keyword` | `size × 0.9`，size 常用 72–88 | ≤8 字，墨色，描边 `max(5, size×0.07)` 纸色，淡入 + 从 1.06 缩到 1 |
| 页眉 | “国富论”26（红底白字小方块）；章节名 28（600 字重、字距 0.08em、85% 不透明）；“No.25”28（55% 不透明） | 左右 x 64，下面 1.5px 细线（18% 不透明） |
| 三格 `PartBar` | 28 | 胶囊高 58、圆角 29、4px 彩铅棕边、白底，间距 14 |

| 公式卡 | 标题条 40、三行 44、圆圈数字 38 | 见第十三节 |

## 五、背景：纸上的虚化小镇（`PaperTown`）

从下往上叠五层（数值照抄）：
1. **彩铅小镇**：蓝天粉云、两层远山、石子街，后排一溜铺子（裁缝、鞋匠、铁匠、屠户、金匠、书铺、鱼铺，招牌只画图标）。整层 `blur(5px) sepia(0.15) saturate(0.75)`，随时间极慢地放大（300 帧内放大 3%）
2. **纸色罩**：整屏 `rgba(241,234,219,0.58)`（纸色 58% 不透明）——小镇只剩淡淡的影子
3. **冷调**（需要时）：径向渐变 `#4A5872 → #232B3B → #1B2130`，不透明度 = `dusk`（0.2–0.3）。每集至少一处冷节拍（截图 `EP25_09`、`EP25_20`）
4. **纸张颗粒**：`feTurbulence` 分形噪声（baseFrequency 0.85、2 层），正片叠底 42%，每 3 帧换一次种子（纸面在轻轻“沸腾”）
5. **四角压暗**：径向渐变，中间 60% 透明，四角 `rgba(40,28,10,0.15)`

- 小镇**一直在**（10-26 用户：“不要去掉后面的虚化的景观”），不换成光秃秃的纸，也不换成清晰的小镇
- 场景里需要地点时（城、田、庄园、港口），画成彩铅道具放在前景，不换背景
- 当代场景（“换到今天”）：同一个背景，前景放今天的东西（高楼 `Skyline`、手机），挂“今天”小贴纸

## 六、书页外框（每一帧都有）

**页眉 `Header`**：开头场景（第 0–约 12 秒）不挂，开头场景结束后 12 帧淡入。左：红底“国富论”方块（`#B9412C` 底、纸色字、内描 2px 纸色 + 3.5px 红双线框）+ 章节名“第三篇 · 第3章 罗马帝国倒了以后，城市怎样兴起”；右：“No.25”。暗场（`dark`）时字变纸色。

**三格进度 `PartBar`**（y 186）：三个等宽胖胶囊，写“① 一开始自由吗”这种“同一个问题的三步”（每格 ≤7 字，念着顺）。
- 从三问那句起淡入（从上往下滑 20px）
- 讲到哪一步，那一格**从左往右涂上这一步的颜色**，涂到的那截字变白；这一格放大到 1.06
- 这一步的结论一出，格子涂满、后面弹出“✓”；讲完的格子保持彩色
- 胶囊：白底 `#FFFCF6`、4px 彩铅棕边 `#3E2A20`、下方实心阴影 `0 5px 0 rgba(62,42,32,.16)`

**顶部关键词 `Keyword`**（y 272）：一个镜头一个，≤8 字，**不能和同一时刻的字幕一字不差**（用提炼词、数字或原话）。

**结论章 `Verdict`**（y 284）：上面一行“第一步的结论”（36 号墨色、6px 纸色描边），下面一块印章：这一步颜色的底、纸色 50 号字、3px 墨边、圆角 8、**旋转 -2°**、**右下 8px 朱砂红实心错位阴影**，从 1.5 倍砸下来（10 帧）。口播不念“第一步的结论”，用普通的话说结论。

**字幕**（y 1338，`Episode.tsx` 自动）：
- 一段话（标点隔开）整段同屏：≤14 字正常、15–20 字缩字、>20 字同屏两行；句尾逗号句号不显示
- **卡拉 OK 式**：没念到的字 26% 不透明（灰），念到的字变墨色；关键词念到时变朱砂红、往上跳一下、放大 12% 再回落
- 字幕后面一条纸色半透明带（`rgba(241,234,219,.86)` 上下渐隐，高 190），字带 18px 纸色柔光
- 角色说话：字幕前挂红底白字人名签（“农夫”）；暗场时字变纸色

**画面标签 `TagDiv`**：书页上的批注签——这一步颜色（或墨青、朱砂红）的底、纸色宋体字、3px 墨边、圆角 8、右下 4px 淡阴影 `rgba(27,30,36,.14)`；人物名签放头顶上方，物件签放物件下方或旁边，不压身体。白底赭金边的小签（`过路`、`过桥`）用在道具上的小字。

**卡片 `Card`**（讲道理的图都放卡上）：米白 `#FBF7EF`、3.5px 墨边、圆角 16、右下 8px 淡阴影；左边可加一条 10px 本步颜色竖条。三问卡 = 卡片里一句完整的问题（墨色）+ 下面一行概念名（朱砂红小字，“书里叫‘自由市’”）+ 左边一个小道具图标。

## 七、人物（彩铅 Q 版，当书页插图）

- 只用 `63_…\public\cast\v16\` 里现有的人物图（24 个角色，见 `62_人物与道具清单.md`）；**仓库里没有的角色先告诉用户**，用户用别的 AI 按 `64_新角色出图提示词.md` 出图，不自己画矢量小人顶替
- 样子：手绘彩铅儿童绘本风，暖棕细轮廓线，Q 版大头短身（头约占身高 2/5），圆眼深棕虹膜带白高光，脸颊腮红；纸偶式动画（整张图做动作，不拆骨骼）
- **一个镜头只放和这句话关系最大的一两个人**（正在说话的、正在做旁白说的事的），放大；凑数站桩的一律去掉
- 身高：单人主讲 540–660；两人对话 520–620；开头远景里的小人约 360；圆头像 `Head` 120–150；封面猫狗 70–85
- 站位：脚底在 **y≈1262（FOOT）**；两人左右分开（x≈250 和 x≈820），前排相邻两人留 ≥15px；脚下一个淡淡的椭圆影子（`rgba(80,58,38,0.2)`、模糊 4px）
- 能做：呼吸、眨眼、说话张嘴（按配音逐字对口型）、走路颠步、转身（换视角 + 压扁回弹）、跳一下、点头、摇头、吓一跳（`jolts`）、脸红、头顶符号 `Emote`（！？♪ 汗滴 星星 …，珊瑚红）
- 做不到：抬手、指东西、拿东西、换表情 → 用道具自己动、标签、头顶符号来补
- 职业人物和猫只有朝右的视角，**不镜像**；猫狗不眨眼、第二篇猫狗不说话
- 光晕一律画在人身后、暖金色；脸要有血色（小满用 `xiaoman3`）
- 角色说话时字幕前挂人名签；画面上人物头顶挂墨青色名签（截图 `EP25_10`）

## 八、道具（彩铅手绘，和人物同一套画法）

**画法配方**（每样道具都这样画，代码在 `63_…\src\cast\crayon.tsx`、`src\v16\town.tsx`）：
- 轮廓：`#3E2A20` 深暖棕，3–5px，圆头圆角；直线也要“手抖”——矩形用 `wrect()`（每条边加 2px 左右的随机抖动）
- 填色：中等饱和的暖色块（木头 `#A8764C`/`#C99A6B`、砖石米色、金币 `#E9B949`、布 `#F4EAD5`），外面套 `crayon` 滤镜：边缘粗糙 + 白色蜡笔颗粒（`CrayonDefs light`，颗粒比第一篇淡约四成）
- 原点约定：站在地上的东西原点在底边中心（方便和人物脚底对齐），纸张类在中心
- 一个道具一个参数控制动画（`k` 出现程度、`up` 抬起、`wall` 砌到多高、`fill` 装了多少），见 `62_人物与道具清单.md`
- **不画**：彩旗、花丛、栅栏这类纯装饰；墙上的书架、窗户；真实照片、截图风、扁平线稿风（10-26 用户：第一幕“字体、配色、间距、配图风格都很不搭”）

## 九、演示动画（★★★★★，10-30 起每集必须有）

10-30 用户看完 EP23：“全集都是几个模块没有变化，后续的动画多加一点简单的演示动画，增加趣味，不要复杂就好。”
- **每一步至少 2 个“把道理演出来”的小动画**，一句话说得清怎么动，一个动作 1–2 秒，跟着口播的词起
- 卡片 + 标签 + 田 + 小镇 + 飞来飞去的钱只能当底子，不能全片都是它们
- EP25 用过的（截图 `EP25_10`–`EP25_19`）：关卡横杆抬起放行（`TollGate`）、城墙一层层砌起来 / 城门打开（`CityWall`）、契约上的年限被划掉改成“永远”再盖红章（`Charter`）、钱袋从瘪到鼓再发光（`Purse`）、锁链断开（`Chain`）、跷跷板一头翘起（`Seesaw`）、粗布变细布、布里透出麦穗（`ClothRoll`）、帆船把货运到远方（`Ship`）、高楼一栋栋长出来亮灯（`Skyline`）、日历格一个个弹出“一年”（`Days`）
- 以前几集的：天平往一边歪（`Balance`）、存钱罐越装越满（`SaveJar`）、借条盖“已还”章（`IOU`）、账本一页页打勾（`Ledger`）、防火墙砌起来挡火（`FireWall`）、麦田从左往右铺开（`Highway`）、利率牌数字往下滚（`RateBoard`）、镇子一栋栋长大（`Town`）、地被篱笆分成几块（`LandMap`）……全表见 `62`
- 写剧本时就在知识卡第五节给每一步列好打算用的演示动画

## 十、动画节奏（照抄这些数）

| 动作 | 做法 |
|---|---|
| 东西出现 `popIn` | 12 帧：在锚点词前 6 帧开始，冲到 1.15 倍再回到 1（弹一下） |
| 镜头内切换 `Shot` | 前后各 8 帧叠化；镜头基本静止（`cam="still"`），不乱推乱跳 |
| 关键词、结论章 | 6 帧淡入、4–6 帧淡出 |
| 元素和口播对齐 | 元素在锚点词前 **4–10 帧**出现，**不能晚于旁白**；锚点词在这句里要唯一 |
| 砸重点 `kicks` | 关键词念到时画面轻轻一推（每个场景 2–3 处） |
| 东西飞过去 `Fly` | 沿弧线 20 帧左右，飞完就不画 |
| 音效 | 每个动作配一个：出现 pop、钱 coin、重点 thump、移动 whoosh、跳 boing、成功 twinkle、计时 tick、开头第 2 帧“叮”ding；音量 0.16–0.3 |

## 十二、正文每个镜头必须有

- 和这句话最相关的一两个角色（或一个头像）
- 一样主道具 + **至少一个在动的东西**（人在走、东西在飞、横杆在抬；10-26 用户指着只有一辆车的镜头说“太单调了”）
- 讲什么画什么：道具跟着台词出现，讲道理的图放卡片上
- 角色的反应：吓一跳、头顶符号、点头摇头、跳一下
- 每 30–50 秒一处角色顶嘴（截图 `EP25_15` 大领主登场）
- 数字只用原著里有的；读数分段跳，不显示动画过渡的中间值

## 十三、结尾和公式卡（截图 `EP25_21`–`EP25_24`）

1. 回顾：三张小卡一张张翻出，每张一个本步颜色的小图标 + 一句话

3. “别套错”：交代适用条件
