## 二、从零安装（换电脑）
1. 装 Node.js、Python 3.11+；Edge 自带
2. 复制整个 `D:\AI\短视频\`（`studio\node_modules` 可重装）；第二篇角色原包 `D:\AI\codex\视频项目\…\v16_video_cast` 也要带上
3. `cd D:\AI\短视频\studio` → `npm install --registry=https://registry.npmmirror.com`
4. `pip install numpy scipy imageio-ffmpeg pillow edge-tts`
5. 复制 `.env.example` 为 `.env`，**让用户自己**填 `VOLC_TTS_API_KEY`（AI 不读不转发）
6. 火山引擎开通音色：云舟 2.0、少年梓辛 2.0、甜美桃子 2.0、小天 2.0、大壹 2.0、幽默大爷 2.0、开朗学长 2.0（咪仔 2.0 第一篇用过）；复刻音色 `S_你的复刻音色ID` 要开通 `seed-icl-2.0`
7. Edge 路径不同就改 `produce.py`、`review.py` 的 `EDGE`

## 四、新角色接入流水线（用户出了新图之后）
新图放进素材包 → `cut_v16.py`（拆成单视角透明图，**会重写 manifest**）→ `anchors_v16.py`（眼睛嘴自动定位，**会重写 anchors**）→ `anchors_v16_manual.py`（会说话的手量眼睛嘴手）→ `anchors_v16_grow.py` → `anchors_v16_skin.py` → `anchors_v16_mouthfix.py`（找原画嘴线校正）→ `anchors_v16_mouthbg.py`（盖嘴线的底色）→ 渲 `EP16T-Cover` 张嘴检查卡放大看。
重跑整条链后要再跑 `skin_fix_v16.py xiaoman2 xiaoman2p 253,222,202`（肤色校正版）。脚本都在 `studio\`。
