# 43 · 组件库速查

> **做画面先在这里找现成的，别从零画。** 路径相对 `studio\src\`。
> 第二篇的规矩：**公共部件只从 `src\v16\` 拿**；每集 `world.tsx` 都 `export * from "../上一集/world"`，所以从本集 world 能拿到前面所有集的道具（EP23 → EP22 → … → EP17 → `v16/stage`）。
> 坐标：画布 1080×1920；第二篇人物脚底 `FOOT ≈ 1262`；SVG 放 `<Screen>` 里，HTML 文字卡放外面。

## 一、第二篇公共部件

### `v16/Sprite.tsx`（角色）
| 组件 | 用法 |
|---|---|
| `Sprite` | `id`（角色图 id）、`view`（front / tq_r / pr_r / back / pr_l / tq_l，或 `[[帧, 视角],…]` 转身）、`x`、`y`（脚底，可关键帧）、`h`（身高 px）、`talk`（`useTalk` 给的张嘴量）、`jolts`（吓一跳的帧）、`seed`、`shadow`，还有走路、跳、点头、摇头、脸红等参数 |
| `Emote` | 头顶符号：`x y kind("!"/"?"/"♪"/"sweat"/"spark"/"…") at dur s` |
| `Avatar16` | 字幕旁小头像：`id size`（`Video.tsx` 的 `badge` 用） |

角色 id：`xiaoman3`（小满）、`female2`（小雪）、`ahe`（阿禾）、`amu`（阿木）、`folk_merchant`（商人 / 双胞胎兄弟）、`folk_banker`、`folk_farmer`、`folk_tailor`、`folk_shoemaker`、`folk_smith`、`folk_butcher`、`folk_goldsmith`、`folk_fisher`、`folk_miner`、`folk_clerk`、`folk_mason`、`folk_coalheaver`、`folk_doctor`、`folk_lawyer`、`folk_apothecary`、`folk_actor`、`cat`、`dog`（旧版 `xiaoman`、`xiaoman2`、`xiaoman2p`、`female` 不再用）。

`cast/talk.ts` 的 `useTalk(sceneId)`：`M("农夫", f)` 返回这个角色此刻的张嘴量。

### `v16/stage.tsx`（舞台和道具）
| 组件 | 用法 |
|---|---|
| `PaperTown` | 背景：`f`、`shops`、`dusk`（冷调 0–1）。**第二篇每个场景的底** |
| `Shot` | 一句话里分镜头：`f a b d`（a–b 帧之间显示，前后 d 帧叠化） |
| `Screen` | 1080×1920 的 SVG 画布 |
| `Card` | 米白纸卡：`x y w h k accent`（左边一条本集颜色） |
| `Keyword` | 顶部关键词：`text at out y(326) size color`（≤8 字、不复读字幕） |
| `PartBar` | 页眉下三格进度：`parts from to ticks spans` |
| `popIn(f, at)` / `fade(f, a, b, d)` | 弹出 / 淡入淡出 |
| `Camera` | 推拉：`k cx cy` |
| `Layer soft` | 虚化后排 |
| `TodayCard`、`Sticker`、`Stamp` | 当代卡片、角上贴纸、印章 |
| 图标 | `IcoLoom IcoCoins IcoCloth IcoBread IcoShirt IcoChair IcoHouse IcoBook IcoGear IcoField IcoShop IcoTimber IcoSack IcoLaptop IcoShelf IcoParcel` |
| 道具 | `Ox`、`Furnace`、`MinePump`、`Chest`、`Room`、`Desk` |
| 颜色 | `INK`、`RED` |
