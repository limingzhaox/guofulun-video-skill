# 45 · 命令速查（一页纸）

> 在 `D:\AI\短视频\studio` 下执行（PowerShell）。`<包>` = `D:\AI\短视频\00_交接包_国富论短视频制作手册`。

## 制作
| 做什么 | 命令 |
|---|---|
| 配音 + 配乐 + 时间轴 | `python gen_assets.py epXX` |
| 免费引擎临时预览 | `python gen_assets.py epXX --engine edge` |
| 类型检查 | `npx tsc --noEmit -p .` |
| 出片前总览 | `python review.py epXX` → `_review\epXX_总览.png` |
| 单帧全尺寸静帧 | `npx remotion still src/index.ts EPXX out.png --frame=123 --browser-executable="C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"` |
| 一键出片 | `python produce.py epXX --skip-audio` |
| 只重出封面 | `python produce.py epXX --cover-only` |
| 只重做响度 | `python produce.py epXX --remaster` |
| 老集文件改成带集号 | `python produce.py epXX --rename` |
| 总入口被别的集卡住 | `python produce.py epXX --skip-audio --entry=src/solo51.tsx`（照它写一个只登记本集的入口） |
| 音色试听 | `python audition16.py`、`python audition17.py` |
| 实时预览 | `npx remotion studio` |

## 后台跑 + 日志

python produce.py epXX --skip-audio *> "$env:TEMP\epXX_prod.log"

## 质检（本包工具）
| 做什么 | 命令 |
|---|---|
| 估片长、数“书里”“斯密” | `python <包>\工具\est_length.py epXX` |
| 文案模型腔检查 | `python "%USERPROFILE%\.claude\skills\human-writing\scripts\check_prose.py" <文本文件>` |
| 锚点词检查 | `python <包>\工具\anchors_check.py epXX` |
| 关键词复读字幕 | `python <包>\工具\kwdup.py epXX` |
| 成片按句抽帧 | `python <包>\工具\frames.py "<EPXX_成片.mp4>" "D:\AI\短视频\studio\src\epXX\timeline.json" <输出目录> 0.8` |
| 开头时间线 | `python <包>\工具\hook_timeline.py epXX` |
| 响度 | `python <包>\工具\loudness.py "<EPXX_成片.mp4>"` |
| 发布文案检查 | `python <包>\工具\check_titles.py "<EPXX_发布文案.md>"` |

## PowerShell 注意
- 没有 `&&`，用 `;` 或 `if ($?) { … }`
- 读 UTF-8 JSON 用 Python（`ConvertFrom-Json` 会乱码）
- 中文路径加双引号
