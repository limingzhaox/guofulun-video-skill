# 46 · 常见故障排查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 配音 HTTP 401 / 403 | 密钥、余额 | 让用户去火山控制台看；**不要让用户把密钥发给你** |
| 音色不可用 | 没开通或刚开通 | 控制台开通，等约 1 分钟 |
| `resource ID is mismatched` | 复刻音色用了 `seed-tts-2.0` | 剧本 `tts` 加 `"resource_id": "seed-icl-2.0"` |
| 复刻音色没感情 / 语气说明没用 | 情绪开关对复刻音色无效 | 用 E 版（断句、场景快慢、〔slow〕、`level: gentle`），见 `流程\17` |
| `tsc` 报的错不在本集 | 别的对话正在改别的集 / 心理号 | 不改别人的文件；`produce.py --entry=` 只编本集；成片已出就只补封面 |
| `tsc` 报 `_v5存档` | 存档放进了 `src` | 挪到 `episodes\epXX\_vN存档\` |
| 找不到 `timeline.json` | 没跑 gen_assets | 先配音 |
| 找不到作品 `EPXX` | 没在 `Root.tsx` 登记，或 `index.ts` 的 id 不是大写集号 | 补登记 |
| 角色张嘴和原画嘴线叠在一起 | 新角色没校正嘴线 | 跑 `anchors_v16_mouthfix.py`、`anchors_v16_mouthbg.py`，渲 `EP16T-Cover` 检查 |
| 小满肤色变黄 | 重拆图后肤色校正丢了 | 重跑 `skin_fix_v16.py xiaoman2 xiaoman2p 253,222,202`（新集用 `xiaoman3`） |
| 角色字幕旁没有头像 | `Video.tsx` 的 `WHO` 没加这个名字 | 加上名字 → 角色图 id |
| `PartBar` 打勾时间不对 | ticks / spans 用错场景 | ticks = 每步场景最后一句的 from；spans = 每步的场景起止 |
| 预告字挂到最后一帧 | 用了 `L.e(0)`（含句尾 ⏸） | 用 `useWordAt` 的词锚点 |
| HTML 文字不显示 | 放进了 SVG `<Screen>` / `<Stage>` 里 | 放到外面 |
| 锚点帧不对 | 词不唯一 / 句号错位 | `工具\anchors_check.py` |
| 文件名不带集号 | 老集 | `produce.py epXX --rename`（已发布的不改） |
| 响度不对 | 混音参数被改 | `V3.base` 应为 0.34；`--remaster` |
| PowerShell 读 JSON 乱码 | PS 5.1 编码 | 用 Python |
| 删除临时目录被拦 | 系统保护 | 覆盖写，不删 |
| 网页抓原文只拿到一部分 | 古登堡页面太长 | 按 offset 分段，或用 Wikisource 按章抓 |
| 用户说“没有同步好记忆” | 别的对话里定的东西这个对话不知道 | 翻审核记录改稿记录、`_历史版本`、规划表、AI 记忆；以后当场写进去 |
