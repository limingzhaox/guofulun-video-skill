## 三、每集要建的文件（`studio\src\epXX\`，照 EP23）
| 文件 | 内容 |
|---|---|
| `world.tsx` | `export * from "../ep22/world"`（继承上一集所有道具和 v16 部件）；本集 `PARTS`（三格：n、short ≤7 字、col）、本集新道具、`Verdict`（结论章）、`FormulaXX`（公式卡） |
| `scenesA/B/C.tsx` | 场景：A = hook、menu、第一步；B = 第二、三步；C = ending、cta |
| `Video.tsx` | SCENES 映射；`WHO`（字幕名 → 角色图 id）；`PartBar`（from 三问那句、ticks 每步最后一句、spans 每步的场景段）；`<Episode progressAt="none" mix="v3" cold look="paper" overlay={BAR} badge={…} />` |
| `Cover.tsx` | `<BookPoster {...P} bookS={0.8} />` + `peek`（猫狗）+ `motif`（本集道具）；横屏 `BookPosterWide`（10-30 起，见 `流程\22`） |
| `index.ts` | `export const episode = { id: "EP23", Video: EP23, Cover, CoverWide, tl: TL23 }` |
| `timeline.json` | gen_assets 生成，不手改 |

`src\Root.tsx`：`import { episode as ep24 } from "./ep24";` 并加进 `EPISODES` 数组。Root 自动登记 `EPXX`、`EPXX-Cover`、`EPXX-Cover34`、`EPXX-Cover43`。

## 四、命名（`模板\归档命名规范.md`）
- 集号：`ep24`（目录、命令）/ `EP24`（作品 ID、文件名前缀）；版本后缀一个字母（`ep15s`）
- 成片文件夹：`EP24_第三篇第2章_主题`（主题 2–6 字，能当口头禅念；简体；阿拉伯数字；不带日期版本号空格括号 # / +）
- 文件夹里：`EP24_成片.mp4`、`EP24_封面.png`、`EP24_封面_3比4.png`、`EP24_封面_横屏.png`、`EP24_发布文案.md`；固定名：`字幕.srt`、`剧本.md`、`知识卡.md`、`审核记录.md`
- A/B 两版都要留时在 `_历史版本\` 手工标 `EP21_成片_v1_20261028.mp4`；不许出现“最终版、定稿、new、副本”
- 对外交付：`国富论EP24_主题_用途_vX_YYYYMMDD.mp4`
- 场景 id 短英文小写；存档放 `episodes\epXX\_vN存档\`（不放 `src`）
