## 第 1 关：剧本审核（配音之前）

**开头（★★★★ + ★★）**
- [ ] 用户选定的开头（写明日期）；候选都写了“书里的问题 → 观众心里那句话”
- [ ] 第一屏大字 ≤12 字；口播第一句 ≤2.5 秒；假设类带“假如”
- [ ] 2.5–6 秒本集角色说具体损失 / 委屈，是故事里的人
- [ ] 第 3 句“《国富论》里说……”半张牌，不说为什么
- [ ] 三问一句 ≤6 秒；第 18 秒前进故事；前 30 秒有顶嘴
- [ ] 没有“你有没有想过”、没有念“三件事”、没有“出人意料”

**一集一个问题（★★★）**
- [ ] 三步是同一个问题，第三步是边界问题；三格每格 ≤7 字、念得顺
- [ ] 一个案例到底，少换比喻
- [ ] 中段 3–4 处真异议，每处改变解释方向
- [ ] 点名一个概念：书里叫法 + 今天的说法（标明）
- [ ] 结尾“别套错”；回顾压成一句；“回到开头”最多两次
- [ ] **开拍前五问**写进审核记录

**原著与准确**
- [ ] 知识卡全列，服务本问题的论证链完整，略的有理由
- [ ] 每个数字、例子有原文；限定词保留；不替斯密说话
- [ ] facts 分三类：原著主张 / 现代解释 / 创作示例

**文案（G 节）**
- [ ] 8 条逐句念过 + `check_prose.py`；改了哪几句写清
- [ ] 角色台词单独一行、名字在 cast 里；一段话尽量 ≤20 字
- [ ] 不让观众回答；“斯密”≤2；不“我认为”；不“先猜一猜”
- [ ] 片长估算：标准 3:45–4:30 / 试验 2:50–3:15

**合规（`33`）**
- [ ] 不点名负面评价国家地区；不评价今天的政策；不制造恐慌；不编真人；不给投资建议

**角色**
- [ ] 只用仓库里的角色；缺的已经告诉用户

## 第 2 关：成片审核

**开头时间线**（从 timeline 读出写进记录）
- [ ] 第一句几秒、角色几秒、书名几秒、三问几秒、几秒进故事、顶嘴几秒

**画面**
- [ ] `anchors_check.py` 锚点全部在台词里；`kwdup.py` 关键词不复读字幕
- [ ] 两轮抽帧最后一轮零问题；场景交接中途帧看过
- [ ] 第 0 帧宋体大字 + 彩铅物件、“叮”卡在弹出帧、大字只出已念到的
- [ ] 每个镜头只放相关角色、够大、有表情 / 动作；主道具之外有在动的东西
- [ ] `PartBar` 按步涂色打勾；结论章完整；第一部分结尾回扣开头画面
- [ ] 至少一处冷节拍（`PaperTown dusk`）；转场 page ≥2、ink ≥2
- [ ] 画面数字和原著一致，无过渡中间值
- [ ] 公式卡标题 + 3 行，念完停 2–3 秒，预告字淡出

**声音**
- [ ] -14 LUFS、真峰值 ≤ -1 dBFS、P90−P10 ≤ 3 dB；角色音色对；没读错字

**封面**
- [ ] question 版式、书 0.64、两行问题主谓齐全、腰封不剧透、右下小角色 + 表情不挡道具、猫狗彩蛋、中文“第 XX 集”；三张都看

**发布文案**
- [ ] 3–4 个标题 ≤20 字（至少 1 个二选一）；描述；经济学概念小节 80–150 字；20 + 5 标签；置顶评论先讲经济学、不加互动；20–22 点；每块代码框

**好视频六个特征**（10-26）
- [ ] 前 3 秒有钩子 / 讲清楚一件事（一句话说出来写进记录）/ 节奏有起伏 / 声音舒服 / 看完有获得感 / 有人味
