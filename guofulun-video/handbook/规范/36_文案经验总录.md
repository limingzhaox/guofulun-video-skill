# 36 · 文案经验总录：选题、钩子、剧本、标题、封面、发布（EP01 到 EP25，截至 2026-10-31）

> 这是一页总账：每一环**现在怎么写**、**为什么**（用户原话或数据）、**照哪一集**。细则在 `流程\11–16、22、23`，每集实际用的例子在 `规范\35`，踩过的坑在 `规范\32`。
> 规矩改过十几版，这里只写现行的；冲突时以 `D:\AI\短视频\CLAUDE.md` 最上面星号最多的那段为准（现在是 ★★★★★ 10-30）。

---

## 一、选题：一集一个问题

- 按原著章节走，一集一章（或一节）。写剧本前把这一章的论证要点**按原文顺序全部**列进知识卡，每条附英文原句 + 中文意思；不讲的写“略”和原因，核心论证链不断（`流程\12`）
- **一集只解决一个问题**（★★★ 10-28）：交付从“讲完一段原著”变成“用一段原著，让观众弄懂一个现实问题”。四层：场景（进得来）→ 机制（看得懂）→ 概念（记得住）→ 适用条件（靠得住）
- 先把**书里的问题**翻成**观众心里那句话**（★★★★ 10-29）：大家都攒钱国家会更穷吗 → 我省吃俭用攒钱，难道错了？；第三篇起原著离今天远，就用一个完整的“为什么”问句（“欧洲大片的地，为什么几百年都没人好好种？”）
- 现实处境要带，但不下“经济下行”这类断言，不评价今天的政策，不给投资建议，不点名评价哪个国家地区穷（`规范\33`）

## 二、开头（现行 ★★★★★，照 EP23 第三版、EP24、EP25）

| 时间 | 写什么 | 例子 |
|---|---|---|
| 0–4 秒 | “**你有没有想过，＋本集问题**”的完整问句（开头语速 14，从容不着急） | “你有没有想过，城里人和乡下人，到底谁养活了谁？” |
| 4–12 秒 | 本集角色开口说**具体的损失或委屈**（先给结局后讲过程），故事里的人，不编真人真事 | 农夫：“这点钱让老爷知道了，就归他了……” |
| 第 3 句 | “《国富论》里说，……”给半张牌，不说为什么 | “《国富论》里说，那时候乡下归老爷管……城里才安全。” |
| 三问 | 一句话 ≤6 秒问完同一个问题的三步，第三步是**边界问题** | “城里人一开始就自由吗？城里的自由是怎么换来的？城里富了，乡下跟着富了吗？” |
| 19–20 秒 | 进故事 | |
| 前 30 秒 | 至少一次角色反问或顶嘴，像聊天不像上课 | EP10：“我们手慢了？”“为什么？” |

- 开头**先写 3–4 个候选给用户挑**，每个写到三问卡（`流程\13`）；**用户定的开头、封面问题、标题不能被后来的诊断换掉**（10-29 EP22 教训）
- 不用：“这一集讲三件事”目录；“出人意料”横幅；“先猜一猜”；“评论区打 1/2”、选项卡、倒计时（**不让观众回答**，10-23）；假结论（“银行越多你越穷”）、制造恐慌、编造真人真事；开头点名洛克、孟德斯鸠（说“好多大学者都以为”）；“你知道吗”和“为什么……？”叠在一句里（10-31）
- 第一句的演变和每集实例见 `规范\35` 第四节

## 三、正文结构

- 三步 = 同一个问题的三步（顶部三格写成三个短问句，每格 ≤7 字、念着顺：“① 一开始自由吗 ② 自由是怎么来的 ③ 乡下跟着富吗”）
- **同一个案例从头用到尾、少换比喻**：一组人物、一个场景，换的只是金额、时间、去向（10-28 复盘批评 EP18、EP19 比喻太多：房子、水塘、抽屉、大路、车道、防火墙、天平）
- 每一步 = 问题 → 书里的例子 → 今天也一样（标“当代例子，非原著”）→ 一句短结论（画面上盖结论章，口播用普通的话说）
- **中段每 30–50 秒一个真不服气的异议**，由角色说出观众心里的反驳，它要改变解释的方向，不是递话（“那我花掉的不也养活了人？”）
- **点名一个概念**：书里的叫法 + 今天的术语（第一次说时讲明“今天的说法”“后来的经济学家说的”），不把现代术语说成斯密原话
- 第一部分结尾回扣开头同一个画面，放完整结论和金句（第二钩）；全片回扣最多两次
- “斯密”全片 ≤2 次；观点只在一两个重点用“所以……”点出，不加“我认为”
- 每一步至少 2 个演示动画（★★★★★ 10-30），写剧本时就在知识卡第五节列好（`画风\60` 第九节）
- **片长 4–5 分钟**（10-30 起不再压缩，审核按 4:00–5:00）；按约 350 字 / 分钟估（`工具\est_length.py`）

## 四、结尾（照 EP25）

回扣开头画面 → 一句替观众松口气的翻转 → 台阶回顾（一句话点出书里的专有名词，卡片和公式卡同步写上）→ “**别套错**”：交代适用条件（书里那个年代、什么前提下成立）→ “**下次……先问一句：……？**”（一句能带走的判断方法）→ 公式卡（标题条 + 3 行，以书里的说法开头）→ “下一集：……”预告字念完就淡出 → 念完只停 2–3 秒

## 五、一句一句怎么说（配音前逐句念出声，`流程\16` / 审核清单 G 节 15 条）

- 一听就懂，不用在脑子里换算；主语清楚，同一个东西全片同一个叫法；口语、不拗口，长句拆短
- 用词准确、常识核对（金银是重的；“租子”一词两义不用）；单位用原文的（镑、先令、盎司）
- 因果不过度：原著说“似乎、也许”的不说成“就是、一定”；保留限定词
- **不省词、意思说全**（10-30 EP24）：口语化只换说法不删意思，每句的主语、动作、对象、结果都念出来——“长子继承，地只传大儿子，一分不分”→“一条叫长子继承，父亲的地全部传给大儿子，别的儿子一块也分不到”
- 不用压缩俗语、含糊比喻代替说明（“地就是兵马”“挡着”“算总账”）；判断词照原文力度（不说“比什么都荒唐”）；不写病句
- **每句单独听也懂**，不靠观众补上一句的省略
- **一句只用一种语气**（10-31 EP25）：要问就只问，要讲就只讲
- **书里的制度和名目第一次出现就用大白话讲清**（10-31 EP25）：谁给谁交钱、交了换来什么、为什么能这样；讲“A 等于 B”要一步一步按因果讲
- 角色台词单独一行、行首“名字：”，否则会被旁白念掉
- 最后再跑一遍 human-writing 的 `check_prose.py`

## 六、标题（发布文案里给 3–4 个）

- 每个 ≤20 字、主谓齐全，**不加“Vibe知识大赏｜”前缀**（10-24 起）
- 第一个 = 开头那个问题；至少一个人人能猜的**二选一思想实验**（“把一期彩票全买下来，稳赚还是稳赔？”）；一个用书里最反常识的数字或事实（“十万镑钞票只留两万金银，够还是不够？”）
- 口头禅 +“为什么你……”（EP10 爆款：“钱多事少离家近的工作，为什么你永远找不到？”）
- 每个标题放进单独的代码框，方便一键复制

## 七、封面文字

- 两行 = 片子开头那个问题，**两行合起来是一句主谓齐全的话**，说清问的是哪样东西（反例“为啥有的越买越贵，有的越买越便宜”主语含糊）；每行 ≤9 字左右
- 腰封吊一个数或一个反常识的事，**不给答案**（“工资里藏着五样东西”“躲过老爷一年，就永远自由”）
- 标题、封面、腰封、发布文案和片中说法一致（EP22“最多 24 倍”改“有时能多出”时，口播、三张封面、文案一起改）

## 八、发布文案（`流程\23`、`模板\发布文案模板.md`）

- 结构：标题 3–4 个 → 作品描述 → **这一集讲的经济学概念**（80–150 字，10-28 起）→ 话题标签（一次给全 15–20 个让用户挑 + “只能放 5 个时”）→ 置顶评论 → 发布设置；**每一块一个代码框**
- 置顶评论**先讲本集的经济学**：概念、原著出处、现代解释的归属、下期预告；**不加互动提问**（10-28、10-29）
- 勾选“内容由 AI 生成”；发布时间晚上 20–22 点（粉丝活跃高峰）
- 话题：活动期（#vibe知识大赏，截止 2026-10-31）必带；活动结束后换成 #涨知识
- 发布后第 3 天把播放、5 秒完播、涨粉填进规划表；5 秒完播 <40% 说明钩子不够强

## 九、和用户怎么配合（最容易出错的地方）

- 每集必须先问的：开头候选、剧本过目、仓库里没有的新角色、片长 / 画风 / 角色 / 配色 / 版式 / 封面 / 音色的改动、外部意见里和已定规则冲突的部分
- 用户在对话里定下的东西，当场写进那一集的 `审核记录.md`（多个对话同时做，别的对话才看得到）
- 用户指出的每个错误：改掉 + 写进 `模板\审核清单.md` F / G 节 + 告诉用户写在哪
- 交付时如实说做了什么、哪些没做、哪些没验证
