# 01 · 新窗口启动说明（在另一个 AI 对话里完整重现工作）

> 目标：新开一个 AI 对话，它不知道之前聊过什么，读完这里列的文件后，能**按同样的标准、流程、质量**做下一集，并且知道哪些事必须先问你。

## 一、先确认用的是哪种 AI 环境
| 情况 | 能不能完整重现 | 怎么做 |
|---|---|---|
| **A. 同一台电脑的 Claude Code / Claude 桌面版“代码”**，工作目录 `D:\AI\短视频` | ✅ 最好 | `CLAUDE.md`、AI 记忆、项目技能 `guofulun-video` 都会自动加载；粘贴 `02_启动提示词.txt` 完整版即可（也可以直接说“用 guofulun-video 技能做 EP24”） |
| **B. 别的能读写本机文件、能跑命令的 AI 工具**（Codex、Cursor 等），打开 `D:\AI\短视频` | ✅ 可以 | 不会自动加载，**必须**粘贴完整版提示词，让它按顺序读文件 |
| **C. 网页版聊天 AI**（不能读本机文件、不能跑命令） | ⚠ 只能做一部分 | 只能帮写知识卡、开头候选、剧本、发布文案；配音、画面、出片做不了。上传本包 `规范\`、`流程\11–16`、`流程\23`、样板 EP23 的剧本和发布文案，以及原著那一章的原文 |
| D. 换了电脑 | 先装环境 | 按 `技术\40_环境搭建.md`；整个 `D:\AI\短视频\` 和角色原包 `D:\AI\codex\视频项目\…\v16_video_cast` 都要带上；密钥你自己填 |

## 二、操作步骤（A / B）
1. 开新对话，工作目录选 **`D:\AI\短视频`**（不是 `studio`，也不是本交接包），允许它读写这个文件夹、运行 python / npx
2. 粘贴 `02_启动提示词.txt` 的**完整版**
3. 等它读完、回一份“理解确认”（进度、流程、先问的事、关键数字、画面要求、新旧冲突、它要你确认的事）
4. 用下面的验收问题抽查 3–5 个
5. 下达任务，例如：“做 EP24（第三篇第 2 章），先给我几个开头候选。” 它应该：读规划表 → 抓原文 → 填知识卡 → 写 3–4 个开头候选（含需要的角色）→ **停下来等你选**

## 三、验收问题
| 问它 | 正确答案（要点） |
|---|---|
| 开头第一句有什么要求？ | 观众心里那句话；第一屏大字 ≤12 字、口播 ≤2.5 秒；假设类加“假如”；不用“你有没有想过” |
| 第 2.5–6 秒放什么？第 3 句说什么？ | 本集角色说具体的损失 / 委屈（不编真人）；第 3 句“《国富论》里说……”给半张牌 |
| 三问卡怎么做？ | 同一个问题的三步，第三步是边界问题；口播一句 ≤6 秒；卡 = 问题 + 概念名；第 18 秒前进故事；不说“出人意料” |
| 一集讲几个问题？ | 一个；一个案例到底少换比喻；中段真异议；点名一个概念；结尾“别套错” |
| 哪些事要先问你？ | 开头候选、剧本过目、仓库没有的新角色、片长 / 画风 / 角色样子 / 封面版式、外部复核里和已定规则冲突的、重做已发布的集 |
| 第二篇画面长什么样？ | `look="paper"` 书页外框 + 宋体 + 朱砂红 + `PaperTown` 纸色虚化小镇 + v16 彩铅角色当插图；进度用页眉下的 `PartBar`；第 0 帧宋体大字 + 彩铅物件；每个镜头只放相关角色、主道具外还有在动的东西 |
| 片长？公式卡停多久？ | 标准 3:45–4:30；EP22、EP23 在试 3 分钟；公式卡念完停 2–3 秒 |
| 置顶评论写什么？什么时候发？ | 先讲本集的经济学，再写出处和现代解释的归属、下期预告，不加互动；晚上 20–22 点 |
| 文件名？ | `EPnn_成片.mp4`、`EPnn_封面_3比4.png`、`EPnn_发布文案.md` 带集号 |
| 外部诊断说开头有问题，你会直接换掉开头吗？ | 不会；用户定的开头不动，只改诊断点到的那一句，要动先问 |
| 能让观众在评论区打 1 或 2 吗？ | 不能 |
| 回复用什么语言？ | 全部中文 |

答错的让它重读对应文件（每个答案在本包都有出处）。

## 五、新 AI 的底线
1. 全部中文
2. 开头、剧本、新角色、方向性改动先问；其余做完再交付
3. 不读不转发密钥；不登录抖音；下载前先问
4. 不改别的对话 / 心理号的文件；已发布的集不重做；用户定的开头不擅自改
5. 用户指出的每个错误写进规范，并告诉用户写在哪
6. 交付时如实说没做 / 没验证的

- 画面问题让它按 `流程\20` 抽帧给你看
- 把具体哪里不一样告诉它，并要求写进规范
