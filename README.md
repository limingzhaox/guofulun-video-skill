# guofulun-video：《国富论》科普短视频制作技能

抖音号「看得见的手」（把经济学，画给你看）做《国富论》科普短视频的整套方法，打包成一个 Claude Code 技能。从选题、读原文、写知识卡、写开头、写剧本、配音、画面、抽帧质检、出片、封面，到发布文案和数据复盘，每一步都写清楚了做法和踩过的坑。

版本：2026-10-29（覆盖到第三篇 EP23）。

## 怎么装

把 `guofulun-video` 整个文件夹复制到下面任意一处：

- 只给这个项目用：`<项目目录>\.claude\skills\guofulun-video\`
- 所有项目都能用：`%USERPROFILE%\.claude\skills\guofulun-video\`

装好后在 Claude Code 里说“做下一集”“写开头候选”“写发布文案”之类的话，技能会自动加载；也可以直接输入 `/guofulun-video`。

## 用之前要知道

- 这是**方法手册**，不含制作工程本身。真正出片要用 `studio` 工程（Remotion 4 + React/TypeScript + Python 脚本）、角色图素材和火山引擎豆包语音 2.0 的密钥，这些都没有放进仓库。
- 手册里的路径按作者电脑写（工作区 `D:\AI\短视频`，工程 `D:\AI\短视频\studio`）。换了位置，按 `handbook\技术\40_环境搭建.md` 改路径；`工具\` 里的脚本可以设环境变量 `GUOFULUN_STUDIO` 指向你的 studio 目录。
- 工具脚本依赖：`pip install imageio-ffmpeg pillow`。
- 规则以 `handbook\规范\30_规则优先级与版本演进.md` 为准：星号越多越新，新旧冲突时听新的。
- 内容只讲原著，不构成任何投资建议。
