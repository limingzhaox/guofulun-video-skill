# guofulun-video：《国富论》科普短视频制作技能

抖音号「看得见的手」（把经济学，画给你看）做《国富论》科普短视频的整套方法，打包成一个 Claude Code 技能。从选题、读原文、写知识卡、写开头、写剧本、配音、**画面**、抽帧质检、出片、封面，到发布文案和数据复盘，每一步都写清楚了做法和踩过的坑。

版本：2026-10-31（覆盖到第三篇 EP25）。这一版新增“画风”一册：画面的确切数值、成片参考截图，和一个能单独跑起来的最小工程（源码 + 人物图 + 字体），换一台电脑也能做出一模一样的画面。

## 怎么装

把 `guofulun-video` 整个文件夹复制到下面任意一处：

- 只给这个项目用：`<项目目录>\.claude\skills\guofulun-video\`
- 所有项目都能用：`%USERPROFILE%\.claude\skills\guofulun-video\`（Mac / Linux：`~/.claude/skills/guofulun-video/`）

装好后新开一个会话，说“做下一集”“写开头候选”“写发布文案”之类的话，技能会自动加载；也可以直接输入 `/guofulun-video`。

## 想做出一样的画面

画风的真身在代码和人物图里，光看文字描述做不出来。照这三步：

1. 读 `handbook/画风/60_画风总纲.md`，看 `handbook/画风/61_参考画面/00_EP25总览_24格.jpg`
2. 照 `handbook/画风/63_画面源码_最小工程/README_怎么跑起来.md` 装好最小工程（Node.js 20+、Python 3.10+、一个 Chromium 内核浏览器）
3. 先渲 EP25 的封面和一帧正文，和参考截图比对；一样了，新的一集照 `src/ep25/` 复制改

配音用火山引擎豆包语音 2.0，密钥自己填进 `.env`（仓库里只有空模板 `.env.example`）。

## 用之前要知道

- 手册里的路径按作者电脑写（工作区 `D:\AI\短视频`，工程 `D:\AI\短视频\studio`）。在别的电脑上用最小工程代替 studio；`工具/` 里的脚本可以设环境变量 `GUOFULUN_STUDIO` 指向你的工程目录
- 工具脚本依赖：`pip install numpy imageio-ffmpeg pillow`
- 规则以 `handbook/规范/30_规则优先级与版本演进.md` 为准：星号越多越新，新旧冲突时听新的
- 人物和画风是这个账号固定的样子；字体是 Noto Serif SC / Noto Sans SC（SIL OFL，来自 @fontsource）和站酷快乐体（SIL OFL，许可文件在最小工程的 `public/fonts/`）
- 内容只讲原著，不构成任何投资建议
